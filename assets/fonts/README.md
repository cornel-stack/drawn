# Vendored fonts

**Kalam** — a handwriting typeface by the Indian Type Foundry.
Licensed under the SIL Open Font License v1.1 (see `OFL.txt`).
Source: https://fonts.google.com/specimen/Kalam

Used for prose, titles and labels (Manim `Text` via Pango). Formulas are **not**
rendered in this font — they use MathTex (standard LaTeX).
