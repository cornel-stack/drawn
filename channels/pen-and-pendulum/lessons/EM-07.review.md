# Fact-check — EM-07 (Kirchhoff's rules: solving any circuit with two equations)

Source: OpenStax *University Physics Volume 2* (CC BY 4.0), §10.3 *Kirchhoff's

## Equation `junctionEq` — ΣI_in = ΣI_out (junction rule)

§10.3, Kirchhoff's first rule, Eq **10.4** (p.425), quoted:

> "Kirchhoff's first rule—the junction rule. The sum of all currents entering a
> junction must equal the sum of all currents leaving the junction:"

(the displayed ΣI_in = ΣI_out equation sat on the blank line after the colon).
This is the board's `\sum I_{in} = \sum I_{out}`. It **follows from conservation
of charge**, p.425:

> "Current is the flow of charge, and charge is conserved; thus, whatever charge
> flows into the junction must flow out."

and the junction defined as a node, p.425: "a junction, or node, is a connection
of three or more wires." The plumbing analogy (narration: a junction is not a
reservoir, what arrives must leave) is OpenStax's own, p.425-426: "an analogy can
be made with water pipes … the volume of water flowing into the junction must
equal the volume of water flowing out of the junction." ✔

## Equation `junctionEq2` — I_1 = I_2 + I_3 (junction rule at node a)

§10.3, junction rule applied to the worked multi-loop circuit at node b, p.429,
quoted:

> "Junction b shows that I_1 = I_2 + I_3 and Junction e shows that … Since
> Junction e gives the same information of Junction b, it can be disregarded."

The board's `I_1 = I_2 + I_3` is exactly this node equation (our circuit labels
the top node *a*; the form is identical — one current in, two out). ✔

## Equation `loopEq` — ΣΔV = 0 ⇒ ε − I_2 R_1 = 0 (loop rule)

§10.3, Kirchhoff's second rule, Eq **10.5** (p.425), quoted:

> "Kirchhoff's second rule—the loop rule. The algebraic sum of changes in
> potential around any closed circuit path (loop) must be zero:"

(the displayed ΣΔV = 0 sat on the blank line after the colon). This is the
board's `\sum_{loop} \Delta V = 0`. It **follows from conservation of energy**,
p.426:

> "In a closed loop, whatever energy is supplied by a voltage source, the energy
> must be transferred into other forms by the devices in the loop, since there
> are no other ways in which energy can be transferred into or out of the
> circuit."

The **sign conventions** (narration: crossing a battery from minus to plus is a
rise; a resistor crossed along the current is a drop of I·R), Figure 10.23 p.428:

> "(a) When moving across a resistor in the same direction as the current flow,
> subtract the potential drop. … (c) When moving across a voltage source from the
> negative terminal to the positive terminal, add the potential drop."

and the drop magnitude, p.426: "The potential drop, or change in the electric
potential, is equal to the current through the resistor times the resistance of
the resistor" (⇒ drop = I·R). The single-loop reduction ε − I_2 R_1 = 0 is the
pattern of the simple-loop example, p.426-427: "Then Kirchhoff's loop rule states
… The loop equation can be used to find the current through the loop." ✔

## Why the system is always solvable (narration claim)

The narration's completeness claim — one junction equation plus as many loop
equations as needed give exactly enough independent equations to find every
branch current — is explicit in the source, p.427:

> "By applying Kirchhoff's rules, we generate a set of linear equations that
> allow us to find the unknown values in circuits. … Each time a rule is applied,
> it produces an equation. If there are as many independent equations as
> unknowns, then the problem can be solved."

The negative-current remark (narration: a negative current just means the arrow
was guessed backwards, the size is still right) is OpenStax's, p.428: "If the
arrow is in the opposite direction of the conventional current flow, the result
for the current in question will be negative but the answer will still be
correct." The branch-counting statement (b branches ⇒ b unknowns ⇒ b independent
equations) is the standard classical-circuit-theory result; OpenStax states the
solvability condition (independent equations = unknowns) but not the b-count
theorem by name — marked **standard**, consistent with the source. ✔

## Worked problem `s4` — junction rule (equations `given`, `step1`, `answer`)

Self-contained: at a junction I_2 = 3 A and I_3 = 1 A flow out, find the inflow
I_1 = I_2 + I_3 (§10.3 junction rule, Eq 10.4; node equation I_1 = I_2 + I_3,
p.429). Numbers are our own. Recomputation:

```python
I2 = 3.0  # A
I3 = 1.0  # A
I1 = I2 + I3
print("I1 = I2 + I3 = 3 + 1 =", I1, "A")
```

Output:

```
I1 = I2 + I3 = 3 + 1 = 4.0 A
```

Board `step1` substitutes 3 + 1; `answer` boxes **4 A** — matches to 0.00 %. ✔

## Worked problem `s5` — loop rule (equations `given2`, `step2`, `answer2`)

Self-contained: the left loop carries battery ε = 12 V and resistor R_1 = 4 Ω;
the loop rule gives ε − I_2 R_1 = 0 ⇒ I_2 = ε/R_1 (§10.3 loop rule, Eq 10.5, with
Figure 10.23 signs, p.428; single-loop reduction p.426-427). Numbers are our own.
Recomputation:

```python
eps = 12.0  # V
R1 = 4.0    # ohm
I2 = eps / R1
print("I2 = eps/R1 = 12/4 =", I2, "A")
```

Output:

```
I2 = eps/R1 = 12/4 = 3.0 A
```

Board `step2` substitutes 12/4; `answer2` boxes **3 A** — matches to 0.00 %. ✔

### Full-circuit consistency

With ε = 12 V, R_1 = 4 Ω (middle branch) and R_2 = 12 Ω (right branch), the two
rules close consistently:

```python
eps, R1, R2 = 12.0, 4.0, 12.0
I2 = eps / R1
I3 = eps / R2
I1 = I2 + I3
print("I2 = eps/R1 =", I2, "A; I3 = eps/R2 =", I3, "A; I1 = I2 + I3 =", I1, "A")
```

Output:

```
I2 = eps/R1 = 3.0 A; I3 = eps/R2 = 1.0 A; I1 = I2 + I3 = 4.0 A
```

So the loop currents (I_2 = 3 A, I_3 = 1 A) feed the junction rule to give
I_1 = 4 A — exactly the s4 answer. The two problems are two faces of one
self-consistent circuit. ✔
