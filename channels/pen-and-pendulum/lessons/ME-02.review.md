# Fact-check — ME-02 (The kinematic equations: where they come from)

Source: OpenStax *University Physics Volume 1* (CC BY 4.0), Chapter 3 *Motion
Along a Straight Line*, §3.4 *Motion with Constant Acceleration* (PDF pp.
115–121, extraction labels pp. 127–137) and §3.3 *Average and Instantaneous
Acceleration* (PDF pp. 107–114). Extracted text:
`sources/text/university-physics-vol1/024-3-4-motion-with-constant-acceleration.md`,
`sources/text/university-physics-vol1/023-3-3-average-and-instantaneous-acceleration.md`.

> Note on quoting: the OpenStax PDF renders its displayed equations as images,
> so the equation glyphs themselves are not present in the extracted text — only
> the surrounding prose that introduces each one, together with the equation
> number (e.g. "3.11", "3.12", "3.13", "3.14") printed in the margin. The
> extraction therefore shows a blank line where each displayed equation sits
> (see the "3.11 / 3.12 / 3.13 / 3.14" stray numbers in the text). Where that is
> so, the quoted line is the sentence that labels the equation, and the symbolic
> form is confirmed against the standard OpenStax equation number. This matches
> the convention recorded in ME-01 and ME-25.

> Note on problem numbers: the four worked examples in §3.4 use OpenStax's own
> data — Example 3.7 (70.0 m/s, −1.50 m/s², 40.0 s), Example 3.8 (dragster, 26.0
> m/s², 5.56 s → 402 m), Example 3.10 (30.0 m/s, −7.00/−5.00 m/s² → 64.3/90.0 m).
> Our two problems use **different numbers of our own** — Problem A (motorcycle,
> 8 m/s, 3 m/s², 6 s) and Problem B (car, 20 m/s → 0, −5 m/s²) — so nothing is
> copied verbatim, as the house rules require. Only the *equations* used are
> OpenStax's.

## Equations

### `vEq` — v = v0 + a t  (final velocity from acceleration and time)
§3.4 "Solving for Final Velocity from Acceleration and Time" (p.116-117), prose
labelling Equation **3.12**:
> "We can derive another useful equation by manipulating the definition of
> acceleration … Substituting the simplified notation … Solving for v yields"
The result (Eq 3.12) is v = v0 + a t, reused immediately as the solving equation
in Example 3.7 ("We calculate the final velocity using Equation 3.12"). The
lesson's slope-of-the-line reading ("each second the velocity climbs by a fixed
amount a") is the §3.3 statement that for a straight velocity-time graph "the
velocity function is a straight line with a constant slope, thus acceleration is
a constant" and "instantaneous acceleration is the slope of the tangent line to
the velocity-versus-time graph" (§3.3, p.110-111, Fig 3.15). Verdict: ok.

### `xEq` — x = x0 + v0 t + ½ a t²  (final position with constant acceleration)
§3.4 "Solving for Final Position with Constant Acceleration" (p.118), prose
labelling Equation **3.13**:
> "We can combine the previous equations to find a third equation that allows us
> to calculate the final position of an object experiencing constant
> acceleration. We start with [x = x0 + v̄ t] … Now we substitute this
> expression for [v̄] into the equation for displacement … yielding"
The result (Eq 3.13) is x = x0 + v0 t + ½ a t², confirmed by Example 3.8's use of
"the equation [x = x0 + v0 t + ½ a t²]". The lesson's area reading (rectangle
v0 t plus triangle ½ a t²) is the geometric decomposition of the area under the
straight v-t line; the "displacement = average velocity × time" step is Eq 3.10
(see `xder`). Verdict: ok.

### `adef` — a = (v − v0)/t ⇒ v = v0 + a t
§3.4 (p.116-117): Eq 3.12 is derived precisely "by manipulating the definition
of acceleration" and §3.4 later makes the rearrangement explicit: "Rearranging
Equation 3.12, we have [a = (v − v0)/t]" (p.121, "let's look at some of the
equations more closely"). The definition of (average) acceleration as the rate
of change of velocity is §3.3's box:
> "AVERAGE ACCELERATION — Average acceleration is the rate at which velocity
> changes" (Eq 3.8, p.108),
and for constant a "the average and instantaneous accelerations are equal"
(§3.4, p.116), so a = (v − v0)/t with the simplified notation (initial time
zero, elapsed time t). The lesson derives v = v0 + a t from this definition —
exactly OpenStax's route to Eq 3.12. Verdict: ok.

### `xder` — v̄ = (v0 + v)/2,  x − x0 = v̄ t
§3.4 "Displacement and Position from Velocity" (p.116), prose labelling
Equations **3.10** and **3.11**:
> "To get our first two equations, we start with the definition of average
> velocity … Solving for x gives us [x = x0 + v̄ t] … where the average velocity
> is [v̄ = (v0 + v)/2]. The equation [v̄ = (v0 + v)/2] reflects the fact that when
> acceleration is constant, [v̄] is just the simple average of the initial and
> final velocities."
So x − x0 = v̄ t (Eq 3.10) and v̄ = (v0 + v)/2 for constant a (Eq 3.11) — exactly
the two parts of the lesson item. The displacement-as-area / average-velocity
picture the lesson narrates is this pair. Verdict: ok.

### `velim` — v² = v0² + 2 a (x − x0)  (eliminating time)
§3.4 "Solving for Final Velocity from Distance and Acceleration" (p.120), prose
labelling Equation **3.14**:
> "A fourth useful equation can be obtained from another algebraic manipulation
> of previous equations. If we solve [v = v0 + a t] for t, we get … Substituting
> this and [v̄ = (v0 + v)/2] into [x = x0 + v̄ t], we get"
The result (Eq 3.14) is v² = v0² + 2 a (x − x0). The lesson's remark that "this
last one carries no time at all" matches Example 3.9: "The equation [v² = v0² +
2 a (x − x0)] is ideally suited to this task because it relates velocities,
acceleration, and displacement, and no time information is required" (p.120).
Verdict: ok.

## Numbers

### Problem `s5` (motorcycle: v = 26 m/s, x = 102 m)

```python
# Problem A: v0=8 m/s, a=3 m/s^2, t=6 s
v0, a, t = 8, 3, 6
v = v0 + a*t                 # Eq 3.12
x = v0*t + 0.5*a*t**2        # Eq 3.13 (x0 = 0)
xcheck = (v0 + v)/2 * t      # Eq 3.10 with Eq 3.11 average, cross-check
print('v =', v)
print('x =', x)
print('x (area cross-check) =', xcheck)
print('s5 check expr 8*6 + 0.5*3*6**2 =', eval('8*6 + 0.5*3*6**2'))
```

output:
```
v = 26
x = 102.0
x (area cross-check) = 102.0
```
s5 check expr `8*6 + 0.5*3*6**2` = `102.0`, equals boxed value 102 (tol 1 %). The
area cross-check via the average velocity (8+26)/2 × 6 = 17 × 6 = 102 m agrees,
confirming the narration. Verdict: ok.

### Problem `s6` (car braking: Δx = 40 m)

# Problem B: v0=20 m/s, v=0, a=-5 m/s^2

dx = (vb**2 - v0b**2)/(2*ab)   # Eq 3.14 solved for (x - x0)
print('stopping distance =', dx)

```

```
s6 check expr `(0**2 - 20**2) / (2 * -5)` = `40.0`, equals boxed value 40 (tol
1 %). The narration's "four hundred over ten, which is forty metres" matches
(400/10 = 40). Verdict: ok.
