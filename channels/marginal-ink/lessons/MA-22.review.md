## Equation `phillipsEq`

`\pi = \pi^e - \beta\,(U - U^*)` — the expectations-augmented Phillips curve;
short-run downward tradeoff, vertical in the long run at the natural rate.

> "The short run upward sloping aggregate supply curve implies a downward
> sloping Phillips curve; thus, there is a tradeoff between inflation and
> unemployment in the short run. By contrast, a neoclassical long-run aggregate
> supply curve will imply a vertical shape for the Phillips curve, indicating no
> long run tradeoff between inflation and unemployment."
> — OpenStax Principles 3e §26.2, "The Neoclassical Phillips Curve Tradeoff", p.636

> "there may be a tradeoff between inflation and unemployment when people expect
> no inflation, but when they realize inflation is occurring, the tradeoff
> disappears."
> — OpenStax Principles 3e §25.3, "The Instability of the Phillips Curve", p.620

## Equation `reEq`

## Problem `s4`

Fisher relation with rational expectations: the nominal rate is the real rate
plus expected inflation, which lenders fully anticipate.

```python
# s4: Fisher relation i = r + pi^e
r = 2        # real rate, %
pie = 4      # expected inflation, %
i = r + pie
print("s4 nominal rate i =", i, "%")
print("check expr 2+4 =", 2 + 4)
```

output:
```
s4 nominal rate i = 6 %
check expr 2+4 = 6
```

Reasoning confirmed: anticipated inflation is priced straight into the nominal
rate (i = 2 + 4 = 6%), so a central bank cannot lower the real cost of borrowing
by creating expected inflation. Boxed value 6%, tol 1% — matches.

## Problem `s5`

Expectations-augmented Phillips curve in the long run: expectations correct and
unemployment at its natural rate, so the gap is zero and the tradeoff vanishes.

```python
# s5: long-run Phillips pi = pi^e - beta*(U - U*)
pie = 5      # expected inflation, %
U = 5        # unemployment, %
Ustar = 5    # natural rate, %
beta = 0.5
pi = pie - beta * (U - Ustar)
print("s5 long-run inflation pi =", pi, "%")
print("check expr 5 - 0.5*(5-5) =", 5 - 0.5 * (5 - 5))
```

output:
```
s5 long-run inflation pi = 5.0 %
check expr 5 - 0.5*(5-5) = 5.0
```

Reasoning confirmed: the unemployment gap is zero, so inflation equals expected
inflation (5%) regardless of the inflation rate chosen — at the natural rate
there is no long-run inflation-unemployment tradeoff; the long-run Phillips curve
is vertical. Boxed value 5%, tol 1% — matches.
