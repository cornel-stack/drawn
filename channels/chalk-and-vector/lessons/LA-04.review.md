# Fact-check — LA-04

Source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), §1.I.3 "General =
Particular + Homogeneous". Local extract:
`sources/text/hefferon-linear-algebra/001-solving-linear-systems.md` (PDF pages
23-33 of the section; line numbers below are into that extract). Our lesson
explains the material in its own words; both worked systems use our own numbers
(not Hefferon's examples). The span / flat / dimension framing is standard; where
we use a term Hefferon words differently, his actual term is cited.

## Theory scenes s2-s3 (`homEq`, `slogan`, `setForm`)

**Homogeneous system, zero vector always a solution (`homEq`).**

> "A linear equation is homogeneous if it has a constant of zero, so that it can
> be written as a1x1 + a2x2 + ... + anxn = 0." — §1.I.3, Def 3.2, p. 24, lines
> 2053-2054

> "a homogeneous system must be consistent since there is always at least one
> solution, the zero vector." — §1.I.3, p. 24, lines 2082-2084

The lesson's "its solution set always passes through the origin" is exactly this:
the zero vector is always a member.

**Solution set is a span; one direction per free variable (`homEq`, `answer2`).**

> "For any homogeneous linear system there exist vectors β1,...,βk such that the
> solution set of the system is {c1 β1 + ... + ck βk | c1,...,ck in R} where k is
> the number of free variables in an echelon form version of the system." —
> §1.I.3, Lemma 3.6, p. 25, lines 2167-2170

> "the set of vectors {c1 β1 + ... + ck βk | c1,...,ck in R} is generated by or
> spanned by the set {β1,...,βk}." — §1.I.3, p. 27, lines 2312-2314

So one free variable gives one direction (a line), two give a plane. Hefferon's
own terms are "generated by / spanned by" and "number of free variables"; the
lesson's "span", "flat", and "dimension = number of free variables" are the
standard geometric reading of this lemma. The closure argument the narration
gives ("multiply any solution by a number and it is still a solution; add two
solutions and the sum is a solution") is Hefferon's Corollary 3.10 reasoning:

> "any scalar multiple of v also solves the homogeneous system ..." — §1.I.3,
> Corollary 3.10 proof, p. 29, lines 2473-2478

**The theorem and its slogan (`slogan`).**

> "Any linear system's solution set has the form {p + c1 β1 + ... + ck βk |
> c1,...,ck in R} where p is any particular solution and where the number of
> vectors β1,...,βk equals the number of free variables that the system has after
> a Gaussian reduction." — §1.I.3, Theorem 3.1, p. 24, lines 2042-2046

> "Remember that theorem with the slogan, 'General = Particular + Homogeneous'."
> — §1.I.3, p. 28, lines 2338-2339

Our `slogan` "general = particular + homogeneous" is verbatim.

**The set form and its one-line proof (`setForm`).**

> "For a linear system and for any particular solution p, the solution set equals
> {p + h | h satisfies the associated homogeneous system}." — §1.I.3, Lemma 3.7,
> p. 27-28, lines 2320-2321

Proof (the narration's "s minus p satisfies the homogeneous system, because the
right-hand sides cancel"):

> "assume that s solves the system. Then s - p solves the associated homogeneous
> system since for each equation index i, ai,1(s1-p1)+...+ai,n(sn-pn) =
> (...s) - (...p) = di - di = 0 ... For set inclusion the other way, take a
> vector of the form p + h ... = di + 0 = di." — §1.I.3, Lemma 3.7 proof, p. 28,
> lines 2324-2336

**The trichotomy (point / line-or-plane / empty).** The narration's three
outcomes are Corollary 3.10:

> "Solution sets of linear systems are either empty, have one element, or have
> infinitely many elements." — §1.I.3, Corollary 3.10, p. 29, lines 2466-2467

> "either empty (if there is no particular solution p), or has one element (if
> there is a p and the homogeneous system has the unique solution 0), or is
> infinite (if there is a p and the homogeneous system has a non-0 solution)." —
> §1.I.3, Corollary 3.10 proof, p. 29, lines 2479-2484

Dimension-zero = point, one = line, two = plane is the standard geometric label
on "number of free vectors = 0, 1, 2". All **ok**.

## s4 — worked problem: real system (`given`, `step1`, `answer`, check)

Our own 2-equation / 3-unknown system `x+y+z=6, x-y+2z=3` (`given`), z free,
parametrised `x=(9-3z)/2, y=(3+z)/2` (`step1`), boxed solution set
`(3,2,1)+s(-3,1,2)` (`answer`). The gate re-runs `check.expr`
`(np.array([[1,1,1],[1,-1,2]]) @ (np.array([3,2,1]) + np.array([-3,1,2])))[0]`,
declared `value: 6.0`.

```python
import numpy as np
A = np.array([[1,1,1],[1,-1,2]])
p = np.array([3,2,1]); v = np.array([-3,1,2])
print("A @ p =", A @ p)             # particular solution
print("A @ v =", A @ v)             # direction solves homogeneous
print("A @ (p + v) =", A @ (p + v)) # s=1 point (0,3,3)
print("p + v =", p + v)
print("s4 check expr:", (A @ (p + v))[0])
```

output:
```
A @ p = [6 3]
A @ v = [0 0]
A @ (p + v) = [6 3]
p + v = [0 3 3]
s4 check expr: 6
```

So (3,2,1) solves the system; (-3,1,2) solves the homogeneous system; at s=1 the
point (0,3,3) still solves the system. `check.expr` returns `6`, matching
`value: 6.0` (tol 1%). Boxed answer is exact. **Verdict: ok.**

## s5 — worked problem: homogeneous twin (`given2`, `step2`, `answer2`, check)

The same coefficients with both right-hand sides zeroed, `x+y+z=0, x-y+2z=0`
(`given2`); z free, `x=-3z/2, y=z/2` (`step2`); boxed `x = s(-3,1,2)` (`answer2`)
— a line through the origin. The gate re-runs `check.expr`
`(np.array([[1,1,1],[1,-1,2]]) @ (np.array([3,2,1]) + 2*np.array([-3,1,2])))[0]`,
declared `value: 6.0` (it confirms the s4 line, shifted twice as far along v,
still solves the real system — i.e. the two shapes are the same line, offset).

```python
import numpy as np
A = np.array([[1,1,1],[1,-1,2]])
p = np.array([3,2,1]); v = np.array([-3,1,2])
print("A @ (p + 2*v) =", A @ (p + 2*v))
print("s5 check expr:", (A @ (p + 2*v))[0])
for s in [1,2,-1,0.5]:
    print(f"  s={s}: A@(s*v) =", A @ (s*v))   # homogeneous line
```

output:
```
A @ (p + 2*v) = [6 3]
s5 check expr: 6
  s=1: A@(s*v) = [0 0]
  s=2: A@(s*v) = [0 0]
  s=-1: A@(s*v) = [0 0]
  s=0.5: A@(s*v) = [0. 0.]
```

Every multiple `s(-3,1,2)` solves the homogeneous system (RHS all zero), and
`p + 2v` still solves the real system — the homogeneous line lifted to p.
`check.expr` returns `6`, matching `value: 6.0` (tol 1%). **Verdict: ok.**

## Not copied from Hefferon

Our two systems use our own coefficients and constants. Hefferon's §1.I.3 worked
examples are `3x+4y=3 / 2x-y=1` (Example 3.3), `3x+2y+z=0 / 6x+4y=0 / y+z=0`
(Example 3.4), the TNT Chemistry system (Example 3.5), `x+2y-z=1 / 2x+4y=2 /
y-3z=0` (Example 3.8, singleton), and `x+z+w=-1 / 2x-y+w=3 / x+y+3z+2w=1`
(Example 3.9, empty). Ours — `x+y+z=6 / x-y+2z=3` with line `(3,2,1)+s(-3,1,2)`,
and its homogeneous twin `s(-3,1,2)` — do not appear in Hefferon. Same theorem,
our numbers.
