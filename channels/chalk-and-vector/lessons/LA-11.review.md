# Fact-check — LA-11

Primary source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Chapter Two
§III Basis and Dimension**, subsections **III.1 Basis** and **III.2 Dimension**
— local extract `sources/text/hefferon-linear-algebra/010-basis-and-dimension.md`
(book pp. 121-135; the lesson cites pp. 121-140). The 2x2 determinant
independence test (used in s5) is Hefferon's §II.1 Exercise 1.43(a) (p. 120),
carried over from LA-10. The lesson explains the material in its own words; both
worked problems use our own vectors, adapted from Example 1.16 and Example 1.2.

## The central claims

**A basis is a linearly independent spanning set (`basisEq`).**

> "A basis for a vector space is a sequence of vectors that is linearly
> independent and that spans the space." — §III.1, Definition 1.1, p. 121,
> lines 13-14

Our `basisEq` = "independent + spanning" is this definition. **ok.**

**Every vector has a UNIQUE representation as a combination of basis vectors
(`coordEq`, `coordEq2`).**

> "In any vector space, a subset is a basis if and only if each vector in the
> space can be expressed as a linear combination of elements of the subset in
> one and only one way." — §III.1, Theorem 1.12, p. 123, lines 259-261

The uniqueness argument the lesson gives (two expressions, subtract, independence
forces equality) is Hefferon's proof:

> "c1 b1 + c2 b2 + ... + cn bn = d1 b1 + d2 b2 + ... + dn bn holds if and only if
> (c1 - d1) b1 + ... + (cn - dn) bn = 0 holds. So, asserting that each
> coefficient in the lower equation is zero is the same thing as asserting that
> ci = di for each i, that is, that every vector is expressible as a linear
> combination of the b's in a unique way." — §III.1, Theorem 1.12 proof, p.
> 123-124, lines 279-285

**Coordinates are relative to a chosen basis (`coordEq`).**

> "In a vector space with basis B the representation of v with respect to B is
> the column vector of the coefficients used to express v as a linear
> combination of the basis vectors ... where B = <b1, ..., bn> and v = c1 b1 +
> c2 b2 + ... + cn bn. The c's are the coordinates of v with respect to B." —
> §III.1, Definition 1.13, p. 126, lines 286-308

That the same vector has different coordinates in different bases is Example 1.14
(p. 123-124): RepB(x+x2) vs RepD(x+x2) differ. **ok.**

**The standard basis for R^n.**

> "For any Rn, En = <(1,0,...,0), (0,1,...,0), ..., (0,0,...,1)> is the standard
> (or natural) basis." — §III.1, Definition 1.5, p. 122, lines 90-143

And RepEn of (v1,...,vn) is (v1,...,vn) itself (Remark/Example after Definition
1.16, p. 125, lines 391-424) — the familiar x,y coordinates the narration refers
to. **ok.**

**All bases of a finite-dimensional space have the same size, which is the
dimension (`dimEq`).**

> "In any finite-dimensional vector space, all bases have the same number of
> elements." — §III.2, Theorem 2.4, p. 131, lines 1021-1022

> "The dimension of a vector space is the number of vectors in any of its
> bases." — §III.2, Definition 2.5, p. 131, lines 1045-1046

> "Any basis for Rn has n vectors since the standard basis En has n vectors.
> Thus, this definition of dimension generalizes the most familiar use of term,
> that Rn is n-dimensional." — §III.2, Example 2.6, p. 131, lines 1047-1049

So R2 (the plane) has dimension 2 and R3 has dimension 3, as the narration
states. **ok.**

**n independent vectors in an n-dimensional space form a basis (`answer2`).**

> "In an n-dimensional space, a set composed of n vectors is linearly
> independent if and only if it spans the space." — §III.2, Corollary 2.14,
> p. 132-133, lines 1097-1098

This is the narration's "in dimension n, any n independent vectors are
automatically a basis." **ok.**

coordinates (5,2) (`answer`). The gate re-runs `check.expr` `5*1 + 2*1`,

**Verdict: ok.**

## Problem s5 — is {(1,1),(1,-1)} a basis of R2? (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own vectors. Test independence by the 2x2 determinant (§II.1 Exercise
1.43(a), carried from LA-10): det[[1,1],[1,-1]] = 1(-1) - 1(1) = -2 (`step1b`,
`step2b`), non-zero, so the pair is independent; two independent vectors in the
2-dimensional plane form a basis by Corollary 2.14 (`answer2`). The gate re-runs
`check.expr` `1*(-1) - 1*1`, declared `value: -2` (the determinant), tol 1%.

```python
import numpy as np
M = np.array([[1,1],[1,-1]], float)   # columns u=(1,1), w=(1,-1)
print("det[[1,1],[1,-1]] =", np.linalg.det(M))
print("s5 check 1*(-1) - 1*1 =", 1*(-1) - 1*1)
```

output:
```
det[[1,1],[1,-1]] = -2.0
s5 check 1*(-1) - 1*1 = -2
```

det = -2 != 0, so {(1,1),(1,-1)} is independent and therefore a basis of R2.
`check.expr` returns -2 = `value`. **Verdict: ok.**
