# Fact-check — LA-02

Source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), §1.I Solving Linear
Systems / Gauss's Method. Local extract:
`sources/text/hefferon-linear-algebra/001-solving-linear-systems.md`. Our
lesson explains the material in its own words; both worked systems use our own
numbers (not Hefferon's). Line numbers below are into that extract.

## s2 — augmented matrix and the three row operations

**Augmented matrix / the vertical bar (`augNote`).** The narration ("the
constants written after the vertical bar") is Hefferon's own description:

> "The vertical bar reminds a reader of the diﬀerence between the coeﬃcients on
> the system's left hand side and the constants on the right. With a bar, this
> is an augmented matrix." — §1.I, p. 18, lines 889-891

**The three elementary row operations (`ops`, `sw`, `sc`, `cmb`).** Exactly
Theorem 1.5:

> "If a linear system is changed to another by one of these operations (1) an
> equation is swapped with another (2) an equation has both sides multiplied by
> a nonzero constant (3) an equation is replaced by the sum of itself and a
> multiple of another then the two systems have the same set of solutions." —
> §1.I.1, Thm 1.5, p. 4, lines 131-136

So each operation **preserves the solution set** ("the two systems have the
same set of solutions", line 136). The non-zero restriction on scaling is also
Hefferon's:

> "Multiplying a row by 0 is not allowed because obviously that can change the
> solution set." — §1.I.1, p. 4, lines 137-138

And Gauss's method gaining/losing nothing:

> "Gauss's Method never loses solutions nor does it ever pick up extraneous
> solutions ... a solution to the system before we apply the method if and only
> if it is a solution after." — §1.I.1, p. 3-4, lines 125-127

**Verdict: ok** — operations and the preservation claim are Thm 1.5 verbatim in
substance.

## s3 — forward pass to echelon form (`echLabel`) and the main system

**Echelon form definition (`echLabel`).** The narration ("each leading entry
strictly to the right of the one above, with nothing but zeros below") is
Def 1.10:

> "In each row of a system, the ﬁrst variable with a nonzero coeﬃcient is the
> row's leading variable. A system is in echelon form if each leading variable
> is to the right of the leading variable in the row above it ... and any rows
> with all-zero coeﬃcients are at the bottom." — §1.I.1, Def 1.10, p. 5,
> lines 245-248

The matrix form ("leading entry in lower rows are to the right of those in the
rows above", lines 856-858) is the same statement for the augmented matrix.

**Main 3×3 system — intermediate matrices verified in numpy.** The forward pass
R2−=2R1, R3−=3R1, then R3+=2R2 reaches the echelon matrix used in s4:

```python
import numpy as np
A = [[1,1,1],[2,3,1],[3,1,4]]; b = [6,11,17]
print('solve:', np.linalg.solve(A, b))
M = np.array([[1,1,1,6],[2,3,1,11],[3,1,4,17]], dtype=float)
M[1] -= 2*M[0]; M[2] -= 3*M[0]
print('after R2-=2R1, R3-=3R1:'); print(M)
M[2] += 2*M[1]
print('after R3+=2R2 (echelon):'); print(M)
```

output:
```
solve: [1. 2. 3.]
after R2-=2R1, R3-=3R1:
[[ 1.  1.  1.  6.]
 [ 0.  1. -1. -1.]
 [ 0. -2.  1. -1.]]
after R3+=2R2 (echelon):
[[ 1.  1.  1.  6.]
 [ 0.  1. -1. -1.]
 [ 0.  0. -1. -3.]]
```

The echelon matrix is exactly `[[1,1,1,6],[0,1,-1,-1],[0,0,-1,-3]]`, matching
the `ech` system in s4, and the solution is `(1, 2, 3)`. **Confirmed.**

## s4 — back-substitution (`ech`, `bs1`, `bs2`, `bs3`, `soln`)

The echelon equations `ech` are the rows of the echelon matrix above
(`x+y+z=6`, `y−z=−1`, `−z=−3`). Back-substitution from the bottom is Hefferon's:

> "So c = 4, and back-substitution gives that h = 1." — §1.I.1, Example 1.4,
> p. 3, line 217

> "Back-substitution gives w = 1, z = 2 , y = −1, and x = −1." — §1.I.1,
> Example 1.11, p. 6, line 292

Arithmetic (each an `ok`):
- `bs1`: `−z = −3 ⇒ z = 3`. Correct.
- `bs2`: `y − z = −1`, with z = 3 ⇒ `y − 3 = −1 ⇒ y = 2`. Correct.
- `bs3`: `x + y + z = 6`, with y = 2, z = 3 ⇒ `x + 5 = 6 ⇒ x = 1`. Correct.
- `soln`: `(x, y, z) = (1, 2, 3)` — matches `np.linalg.solve` above exactly.

The "reversible, never loses or manufactures a solution" claim is Thm 1.5 +
p. 3 (lines 125-127). **All ok.**

## s5 — worked problem (`given`, `answer`, check)

Our own 3×3 system `x+y+z=2, 2x+y+3z=2, x−y+2z=−1` (`given`). Solved by the same
Gauss's-method / back-substitution routine (summary, lines 429-432). The boxed
answer `answer` is `(2, 1, −1)`:

```python
import numpy as np
A2 = [[1,1,1],[2,1,3],[1,-1,2]]; b2 = [2,2,-1]
print('solve:', np.linalg.solve(A2, b2))
print('check expr:', np.linalg.solve([[1,1,1],[2,1,3],[1,-1,2]], [2,2,-1])[0])
```

output:
```
solve: [ 2.  1. -1.]
check expr: 2.0
```

The gate's `check.expr` returns `2.0`, matching the declared `value: 2.0`
(tol 1 %). Boxed answer `(2, 1, −1)` is exact. **Verdict: ok.**

## s6 — the two special cases (`zeronote`)

**Inconsistent: 0 = non-zero ⇒ no solution.** Hefferon:

> "Here the system is inconsistent: no pair of numbers (s1, s2) satisﬁes all
> three equations simultaneously. Echelon form makes the inconsistency obvious."
> — §1.I.1, Example 1.11, p. 7, lines 346-347

> "If any step shows a contradictory equation then we can stop with the
> conclusion that the system has no solutions." — §1.I.1 summary, p. 8,
> lines 429-430

**Redundant: 0 = 0 ⇒ free variable, infinitely many.** The lesson's system
`x+y=2, 2x+2y=5` is a deliberate *inconsistent* illustration (the bad row), and
`zeronote` covers both the `0=1` and `0=0` cases. Redundancy and free variables:

> "shows that one of the equations is redundant." — §1.I.1, p. 7, line 317

> "any pair of numbers satisfying the ﬁrst equation also satisﬁes the second.
> The solution set ... is inﬁnite" (reducing to a `0 = 0` row) — §1.I.1,
> Example 1.15, p. 7, lines 375-383

> "if we reach echelon form without a contradictory equation, and there is not
> a unique solution — that is, at least one variable is not a leading variable —
> then the system has many solutions." — §1.I.1 summary, p. 8, lines 433-435

Note: the lesson's narration glosses `0=0` as "some variable may lead no row
... a free variable" — Hefferon is careful that a `0=0` row is *not itself* the
signal (lines 404, 433-435: the real criterion is a non-leading variable). The
lesson states the correct criterion in the summary sentence ("a free variable
means infinitely many"), so the teaching is sound.

**The three outcomes** (unique / none / infinitely many) are Hefferon's summary
(lines 429-435) directly. **Verdict: ok.**
