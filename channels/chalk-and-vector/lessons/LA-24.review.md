# Fact-check — LA-24

Source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), Topic: Markov Chains
(`024-topic-markov-chains.md`, PDF pp. 313–317) and Topic: Stable Populations
(`039-topic-stable-populations.md`, PDF pp. 468–469). All verdicts `ok`.

## Equation `steadyEq`

`T π = π` — the steady state is the distribution left unchanged by the transition
matrix. The steady state / eigenvalue-1 identity is the Stable-Populations result:

> "The population will be stable if pn+1 = pn and rn+1 = rn so that the matrix
> equation v(n+1) = T v(n) becomes v = T v. We are therefore looking for
> eigenvectors for T that are associated with the eigenvalue λ = 1."
> — Stable Populations, p.468

So `v = Tv`, i.e. `Tπ = π`. Verdict: **ok**.

## Equation `vecEq`

`p = (p_1, …, p_k)ᵀ`, `Σ p_i = 1` — the state is a probability vector.

> "Each vector is a probability vector, whose entries are nonnegative real numbers
> that sum to 1." — Markov Chains, p.314

Verdict: **ok**.

## Equation `stepEq`

`p_{n+1} = T p_n` — one step is multiplication by the transition matrix. The source
writes the step rule as the matrix equation taking the vector of pi(n) to pi(n+1):

> "The matrix is a transition matrix or stochastic matrix, whose entries are
> nonnegative reals and whose columns sum to 1." — Markov Chains, p.314

and (p.313-314) the displayed matrix equation `M · [pi(n)] = [pi(n+1)]`, confirmed
by the Sage example `v1 = v0*M` (Sage multiplies from the right using the transpose;
in our column convention this is exactly `p_{n+1} = T p_n`). Verdict: **ok**.

## Equation `eigEq`

`columns sum to 1 ⟹ λ = 1 exists`.

> "whose entries are nonnegative reals and whose columns sum to 1." — Markov
> Chains, p.314

A column-stochastic matrix has `𝟙ᵀ T = 𝟙ᵀ` (every column sums to 1), so `1` is an
eigenvalue of `Tᵀ` and hence of `T` — standard. Confirmed numerically: for
`T=[[0.8,0.4],[0.2,0.6]]` the eigenvalues are `[1.0, 0.4]` (see Python below).
The eigenvalue-1 existence underpins the Stable-Populations steady-state result
(p.468, λ = 1). Verdict: **ok**.

## Equation `powEq`

`p_n = T^n p_0` — iterating the one-step rule. From Exercise 7(b):

> "Observe that if A v0 = v1 and A v1 = v2 then A² is a transition matrix from v0
> to v2. Show that a power of a transition matrix is also a transition matrix."
> — Markov Chains, p.316

Iterating `p_{n+1}=T p_n` n times gives `p_n = T^n p_0`. Verdict: **ok**.

## Equation `solveEq`

`(T − I) π = 0` — the steady state solves the eigenvector equation for λ = 1.

> "The equation 0 = (λI − T)v = (I − T)v is … and gives the eigenspace of vectors
> with the restriction that p = .1r." — Stable Populations, p.468

With λ = 1 this is `(I − T)π = 0`, equivalently `(T − I)π = 0` (same solution set).
Verdict: **ok**.

## Problem `s4`

```python
import numpy as np
T  = np.array([[0.8, 0.4], [0.2, 0.6]])
p0 = np.array([1.0, 0.0])
p1 = T @ p0
print("p1 =", p1)                 # boxed answer id=answer
print("check expr 0.8*1+0.4*0 =", 0.8*1 + 0.4*0)   # check.expr vs value 0.8
```

output:
```
p1 = [0.8 0.2]
check expr 0.8*1+0.4*0 = 0.8
```

Boxed `p1 = (0.8, 0.2)ᵀ` matches; `check.expr = 0.8` equals `check.value = 0.8`
(tol 1 %). **ok**.

## Problem `s5`

```python
import numpy as np
T = np.array([[0.8, 0.4], [0.2, 0.6]])
s = 0.4 / 0.6
print("s =", s, " (2/3 =", 2/3, ")")             # boxed answer id=answer2
pi = np.array([2/3, 1/3])
print("T @ pi =", T @ pi)
print("steady state verified:", np.allclose(T @ pi, pi))
print("column sums =", T.sum(axis=0))
print("eigenvalues =", np.linalg.eigvals(T))
```

output:
```
s = 0.6666666666666667  (2/3 = 0.6666666666666666 )
T @ pi = [0.66666667 0.33333333]
steady state verified: True
column sums = [1. 1.]
eigenvalues = [1.+0.j 0.4+0.j]
```

Boxed `s = 0.4/0.6 = 2/3 ≈ 0.6667` matches; `check.expr = 0.4/0.6 = 0.6667` equals
`check.value = 0.6667` (tol 1 %). Steady-state vector `(2/3, 1/3)` satisfies
`Tπ = π`, columns sum to 1, and the eigenvalues are `{1, 0.4}` (λ = 1 exists).
**ok**.
