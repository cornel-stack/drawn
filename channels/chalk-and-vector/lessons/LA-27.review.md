# Fact-check — LA-27

All spectral-theorem equations are standard linear-algebra facts. The source
(Hefferon, *Topic: Orthonormal Matrices*) supplies the orthonormal-matrix
characterisation directly (`buildEq`); the remaining spectral-theorem statements
are standard results verified mathematically below. Both worked problems use the
symmetric matrix `[[2,1],[1,2]]`, verified with numpy.

## Equation `spectralEq`

`A = Q Λ Qᵀ` — the orthogonal (spectral) diagonalisation of a real symmetric
matrix. Standard spectral-theorem result, consistent with the orthonormal-matrices
topic. Hefferon, *Topic: Orthonormal Matrices*, p.321-322:

> "the columns are of length one and are mutually orthogonal. This is an
> orthonormal matrix (or, more informally, orthogonal matrix …)"

Mathematical verification: if Q's columns are orthonormal eigenvectors and Λ is
the diagonal of eigenvalues, then `A Q = Q Λ` (eigenvalue equation column by
column), and since Q is orthogonal `Q⁻¹ = Qᵀ`, so `A = Q Λ Q⁻¹ = Q Λ Qᵀ`.
Verified concretely for `A=[[2,1],[1,2]]` below (eigenvectors orthogonal, both
eigenvalues real).

## Equation `symEq`

`A = Aᵀ` — the definition of a symmetric matrix. Standard definition.

```python
import numpy as np
A = np.array([[2,1],[1,2]])
print(np.array_equal(A, A.T))
```
output: `True` — so `A = Aᵀ` holds for the example matrix.

## Equation `realEq`

`λ ∈ ℝ` — a real symmetric matrix has real eigenvalues. Standard spectral-theorem
result, consistent with the orthonormal-matrices topic.

Mathematical proof: let `A x = λ x` with `x ≠ 0`, A real symmetric. Then
`x̄ᵀ A x = λ x̄ᵀ x`. Taking conjugate transpose of the left side and using
`A = Aᵀ = Āᵀ` (A real) gives `x̄ᵀ A x = λ̄ x̄ᵀ x`. Since `x̄ᵀ x = ||x||² > 0`,
we get `λ = λ̄`, so λ is real.

Concrete check: eigenvalues of `[[2,1],[1,2]]` are `3` and `1`, both real:

```python
import numpy as np
w, V = np.linalg.eig(np.array([[2,1],[1,2]]))
print(w)
```
output: `[3.+0.j 1.+0.j]` — both eigenvalues real.

## Equation `orthoEq`

`vᵢ · vⱼ = 0 (i ≠ j)` — eigenvectors of a symmetric matrix for distinct
eigenvalues are orthogonal. Standard spectral-theorem result.

Mathematical proof: let `A vᵢ = λᵢ vᵢ`, `A vⱼ = λⱼ vⱼ`, λᵢ ≠ λⱼ. Then
`λᵢ (vᵢ·vⱼ) = (A vᵢ)·vⱼ = vᵢᵀ Aᵀ vⱼ = vᵢᵀ A vⱼ = λⱼ (vᵢ·vⱼ)` (using A = Aᵀ).
So `(λᵢ − λⱼ)(vᵢ·vⱼ) = 0`, and since λᵢ ≠ λⱼ, `vᵢ·vⱼ = 0`.

Concrete check: eigenvectors `[1,1]` (λ=3) and `[1,-1]` (λ=1) of `[[2,1],[1,2]]`:

```python
import numpy as np
A = np.array([[2,1],[1,2]])
v1, v2 = np.array([1,1]), np.array([1,-1])
print((A@v1).tolist(), (A@v2).tolist(), int(v1@v2))
```
output: `[3, 3] [1, -1] 0` — `A v1 = 3 v1`, `A v2 = 1 v2`, `v1·v2 = 0` (orthogonal).

## Equation `buildEq`

`Q = [v̂₁ v̂₂ ⋯], Qᵀ = Q⁻¹` — Q holds unit (orthonormal) eigenvectors as columns,
and an orthonormal matrix satisfies `Qᵀ = Q⁻¹`. Quoted directly from Hefferon,
*Topic: Orthonormal Matrices*, p.321-322:

> "the columns are of length one and are mutually orthogonal. This is an
> orthonormal matrix (or, more informally, orthogonal matrix since people
> … often use this term to mean not just that the columns are orthogonal but also
> that they have length one)."

For such a matrix, `QᵀQ = I` (columns orthonormal ⇒ each dot product is the
Kronecker delta), hence `Qᵀ = Q⁻¹`. Standard.
