# Fact-check — LA-28

**Scope note.** The extracted Hefferon text has **no dedicated SVD topic** — this
is flagged in the lesson header (lines 2-4). The SVD equations below are the
**standard SVD construction**, built from the spectral theorem (Hefferon Five.II)
applied to the symmetric matrix A^T A. They are documented here honestly as the
standard construction and each is verified mathematically with numpy. The only
genuinely *source-quotable* material in the extracted file concerns orthogonal /
orthonormal matrices (rotations/reflections preserving length and orthogonality),
which grounds the "U and V are orthogonal rotations" claim.

## Master numerical verification

Test matrix `A = [[0, -2], [1, 0]]` (a 90°-rotation composed with a 2× stretch —
chosen because its A^T A eigenvalues are exactly the 4, 1 used in the problems).

```python
import numpy as np
A = np.array([[0.0,-2.0],[1.0,0.0]])
U, S, Vt = np.linalg.svd(A)
# S = [2. 1.]
ATA = A.T @ A                      # [[1,0],[0,4]] — symmetric: True
w, v = np.linalg.eigh(ATA)         # eigenvalues [1. 4.]
np.sort(np.sqrt(w))[::-1]          # [2. 1.]  == singular values
U @ np.diag(S) @ Vt                # reconstructs A exactly: True
V = Vt.T
(1/S[0])*(A @ V[:,0])              # == U[:,0] (up to sign): True
(1/S[1])*(A @ V[:,1])              # == U[:,1] (up to sign): True
```

output:
```
SVD singular values S = [2. 1.]
A^T A = [[1. 0.] [0. 4.]]   symmetric? True
eigenvalues of A^T A = [1. 4.]
sqrt(eigenvalues) sorted desc = [2. 1.]
U Sigma V^T reconstructs A? True
u_0 from (1/sigma)Av matches U[:,0] (up to sign): True
u_1 from (1/sigma)Av matches U[:,1] (up to sign): True
```

Additional reconstruction / pseudoinverse checks:
```python
Ak = sum(S[i]*np.outer(U[:,i],V[:,i]) for i in range(2))
np.allclose(Ak, A)                 # low-rank sum sigma_i u_i v_i^T : True
Splus = np.diag([1/s if s>1e-12 else 0 for s in S])
np.allclose(V @ Splus @ U.T, np.linalg.pinv(A))   # pseudoinverse : True
```
output: `low-rank reconstructs A? True`, `A+ matches np.linalg.pinv? True`

## Equation `svdEq`  `A = U Σ Vᵀ`

Standard SVD construction, flagged in header. Correct standard form: any real
m×n matrix factors as U (orthogonal/orthonormal), Σ (diagonal, non-negative),
Vᵀ (orthogonal/orthonormal). Numerically verified: `U @ diag(S) @ Vt`
reconstructs A exactly (True above). The "U, V orthogonal (rotations)" reading
is grounded in the source:

> "we can easily recognize matrices that represent such a map … the columns are
> of length one and are mutually orthogonal. This is an orthonormal matrix"
> — Hefferon, Topic: Orthonormal Matrices, p.321-322

> "The ﬁrst matrix above represents, with respect to the standard bases, a
> rotation of the plane by θ radians." — p.322

## Equation `sigmaEq`  `σ_i = √λ_i`

Standard SVD construction, flagged in header. The singular values are the
square roots of the eigenvalues of A^T A. Verified: eigenvalues of A^T A are
[1, 4]; their square roots sorted descending are [2, 1] = the singular values
from np.linalg.svd (True above). Non-negativity holds because A^T A is positive
semidefinite.

## Equation `defUEq`  `u_i = (1/σ_i) A v_i`

Standard SVD construction, flagged in header. Correct standard form (the left
singular vectors are the normalised images of the right singular vectors).
Verified: `(1/S[i]) * (A @ V[:,i])` equals `U[:,i]` up to sign for i=0,1 (True
above). Sign freedom is expected and does not affect the factorisation.

## Equation `svdEq2`  `A = U Σ Vᵀ`

Identical standard form to svdEq, restated at the end of the derivation.
Reconstruction verified numerically (True above).

## Equation `lowRankEq`  `A ≈ Σ_{i=1}^{k} σ_i u_i v_iᵀ`

Standard SVD construction (Eckart-Young), flagged in header. Correct standard
form: truncating the SVD to the top k terms gives the best rank-k approximation
in the Frobenius/spectral norm. Verified: summing all rank-1 terms
`σ_i u_i v_iᵀ` reconstructs A exactly (True above); truncation to fewer terms is
the standard best-approximation statement.

## Equation `compareEq`  `A = PDP⁻¹ vs A = U Σ Vᵀ`

Both standard forms. A = PDP⁻¹ is the eigendecomposition / diagonalisation
(Hefferon Five.II). A = U Σ Vᵀ is the SVD. The contrast narrated — one basis vs
two orthonormal bases, square-only vs all matrices — is the standard distinction.
Correct.

## Equation `pseudoEq`  `A⁺ = V Σ⁺ Uᵀ`

Standard SVD construction (Moore-Penrose pseudoinverse), flagged in header.
Correct standard form: Σ⁺ inverts the non-zero singular values and transposes.
Verified: `V @ Σ⁺ @ Uᵀ` equals `np.linalg.pinv(A)` (True above).
