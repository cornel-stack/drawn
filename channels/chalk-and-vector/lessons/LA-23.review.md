# Fact-check — LA-23

Source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), Topic: Linear
Recurrences, PDF pp. 474-481, file
`sources/text/hefferon-linear-algebra/041-topic-linear-recurrences.md`. The
source treats *exactly* this lesson: the Fibonacci recurrence, its matrix form
`[[1,1],[1,0]]`, diagonalisation, the golden-ratio eigenvalues `(1±√5)/2`, and
Binet's closed form. Quotes below reproduce the source lines (OCR artefacts in
the extracted text are noted where they affect reading).

## Equation `binetEq`

`F_n = (φ^n − ψ^n)/√5`, with legend φ = (1+√5)/2, ψ = (1−√5)/2.

> F(n) =
> 1 / √5
> [ ((1 + √5)/2)^n − ((1 − √5)/2)^n ]

Hefferon, Topic: Linear Recurrences, "We want the first component", closed
form, p.476 (src lines 325-342). φ and ψ are the lesson's names for the two
roots the source writes as `(1+√5)/2` and `(1−√5)/2`. Standard restatement with
named symbols — ok.

## Equation `recEq`

`F_{n+1} = F_n + F_{n-1}`.

> F(n) = F(n −1) + F(n −2)
> where F(0) = 0, F(1) = 1   (∗)

Hefferon, Eq (∗), p.474 (src lines 19-21). Index shift (n→n+1) is a trivial
reindexing of the same relation — ok.

## Equation `matEq`

`(F_{n+1}, F_n)ᵀ = [[1,1],[1,0]] (F_n, F_{n-1})ᵀ`.

> ( F(n) / F(n −1) ) = ( 1 1 / 1 0 ) ( F(n −1) / F(n −2) )
> where ( F(1) / F(0) ) = ( 1 / 0 )

Hefferon, matrix formulation, p.474-475 (src lines 56-79). The lesson uses the
n+1 index convention; identical matrix `[[1,1],[1,0]]` — ok.

## Equation `powEq`

`(F_{n+1}, F_n)ᵀ = M^n (1,0)ᵀ`.

> Write T for the matrix and ⃗vn for the vector with components F(n) and
> F(n −1) so that ⃗vn = T^{n−1} ⃗v1 for n ⩾ 1. If we diagonalize T then we
> have a fast way to compute its powers: where T = PDP^{−1} then T^n = PD^nP^{−1}

Hefferon, p.475 (src lines 83-87). The source uses `T^{n−1} v1` with `v1=(1,0)ᵀ`;
the lesson writes `M^n (1,0)ᵀ` under the n+1 convention. Both express "the pair
is a matrix power applied to the starting pair" — same content, consistent
index convention — ok.

## Equation `charEq`

`λ² − λ − 1 = 0 ⇒ λ = (1 ± √5)/2`.

> The characteristic equation of T is λ2 −λ −1 = 0. The quadratic formula
> gives its roots as (1+ √5)/2 and (1− √5)/2. (These are sometimes called
> "golden ratios;" see [Falbo].)

Hefferon, p.475 (src lines 88-93). Verbatim match — the source states the
quadratic and both roots and names them golden ratios — ok.

## Equation `given`

`M = [[1,1],[1,0]], tr = 1, det = −1`.

The matrix is the Fibonacci matrix of the source (src lines 56-79). The source
also gives the 2×2 characteristic-polynomial pattern:

> ( a_{n−1} −λ   a_{n−2} / 1   −λ ) = λ2 −a_{n−1}λ −a_{n−2}

Hefferon, p.477 (src lines 498-505). For Fibonacci `a_{n−1}=a_{n−2}=1`, so this
is `λ²−λ−1`; equivalently `tr(M)=1+0=1` and `det(M)=1·0−1·1=−1`. Verified below
in the s4 Python block. Standard restatement of trace/determinant of the given
matrix — ok.

## Problem `s4`

check expr `(1 + np.sqrt(5)) / 2`, value 1.618, tol 0.01.

print('eigvals:', np.linalg.eigvals([[1,1],[1,0]]))

## Problem `s5`
