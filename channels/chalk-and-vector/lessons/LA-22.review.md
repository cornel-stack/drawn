# Fact-check — LA-22

Diagonalisation `A = PDP⁻¹`, its powers rule `Aⁿ = PDⁿP⁻¹`, and the worked
decomposition of `A = [[2,1],[1,2]]`. The governing passage is Hefferon's
*Topic: Linear Recurrences* (PDF p.475), which states the factorisation and the
powers rule verbatim; the eigenvector equation comes from the eigenvalue
Topics. The two numeric problems are recomputed in Python below.

## Equation `diagEq`  (A = P D P^{-1})

> "If we diagonalize T then we have a fast way to compute its powers: where
> T = PDP−1 then T n = PDnP−1 …"
> — Hefferon, *Topic: Linear Recurrences*, p.475
> (`sources/text/hefferon-linear-algebra/041-topic-linear-recurrences.md`, lines 84–86)

The lesson's `A = PDP^{-1}` is exactly the source's `T = PDP−1` (symbol T→A).

## Equation `eigEq`  (A v_i = λ_i v_i)

> "We are therefore looking for eigenvectors for T that are associated with the
> eigenvalue λ = 1. The equation⃗0 = (λI−T)⃗v = (I −T)⃗v …"
> — Hefferon, *Topic: Stable Populations*, p.~465
> (`sources/text/hefferon-linear-algebra/039-topic-stable-populations.md`, lines 32–33)

> "Suppose that the n×n matrix T has n distinct eigenvalues λ1, λ2, …, λn.
> Then Cn has a basis made of the associated eigenvectors ⟨⃗ζ1, …,⃗ζn⟩.
> … T⃗v = c1λ1⃗ζ1 + c2λ2⃗ζ2 + · · · + cnλn⃗ζn"
> — Hefferon, *Topic: Method of Powers*, p.~461
> (`sources/text/hefferon-linear-algebra/038-topic-method-of-powers.md`, lines 10–13)

`(λI − T)⃗v = 0` rearranges to `T⃗v = λ⃗v`, i.e. the lesson's `A v_i = λ_i v_i`.
Standard eigenvector definition, consistent with source.

## Equation `stackEq`  (A P = P D)

of eigenvalues); right-multiplying by P⁻¹ yields the source's `T = PDP−1`.

## Problem `s4`

```python
import numpy as np
P = np.array([[1, 1], [-1, 1]])   # columns = eigenvectors for lambda=1 and lambda=3
D = np.diag([1, 3])
A = P @ D @ np.linalg.inv(P)
print("P D P^-1 =\n", np.round(A, 10))
print("reconstructs [[2,1],[1,2]]:", np.allclose(A, [[2, 1], [1, 2]]))
print("det(P) =", round(np.linalg.det(P)))        # check: 1*1 - 1*(-1)
print("check expr 1*1 - 1*(-1) =", 1*1 - 1*(-1))  # boxed value 2
# eigenvector sanity
A2 = np.array([[2, 1], [1, 2]])
print("A@[1,-1] =", A2 @ np.array([1, -1]), "(= 1*[1,-1])")
print("A@[1,1]  =", A2 @ np.array([1, 1]),  "(= 3*[1,1])")
```

output:
```
P D P^-1 =
 [[2. 1.]
 [1. 2.]]
reconstructs [[2,1],[1,2]]: True
det(P) = 2
check expr 1*1 - 1*(-1) = 2
A@[1,-1] = [ 1 -1] (= 1*[1,-1])
A@[1,1]  = [3 3] (= 3*[1,1])
```

The boxed answer `A = PDP⁻¹` is exact: PDP⁻¹ reconstructs [[2,1],[1,2]]. The
`check:` block (`1*1 - 1*(-1)` = det P) equals 2, matching the boxed value, so P
is invertible.
