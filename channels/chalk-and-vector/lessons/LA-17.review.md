# Fact-check — LA-17

Primary source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Chapter Three
§VI Projection** (local extract
`sources/text/hefferon-linear-algebra/020-projection.md`, book pp. 275-294).
VI.1 *Orthogonal Projection Into a Line* supplies the projection formula, its
derivation from perpendicularity, and the closest-point reading; VI.3
*Projection Into a Subspace* supplies the generalisation to subspaces. Both
worked problems use our own vectors (A: v=(4,2) onto the x-axis; B: v=(3,1) onto
y=x); the numbers are ours, the method is Hefferon's.

## The central claims

**The orthogonal projection of v onto the line of u is proj = (v·u / u·u) u
(`projEq`).**

> "1.1 Deﬁnition The orthogonal projection of ⃗v into the line spanned by a
> nonzero ⃗s is this vector. proj[⃗s ](⃗v) = ⃗v •⃗s / ⃗s •⃗s ·⃗s" — §VI.1,
> Definition 1.1, p. 276, lines 46-49

With u for Hefferon's s this is exactly `projEq`. **ok.**

**It is derived from the condition that the residual v − cu is perpendicular to
u, i.e. (v − cu)·u = 0 giving c = v·u/(u·u) (`projEq2`, `closestEq`).**

> "Since the line is the span of some vector ℓ = {c ·⃗s | c ∈ R}, we have a
> coeﬃcient c⃗p with the property that ⃗v −c⃗p⃗s is orthogonal to c⃗p⃗s." — §VI.1,
> p. 275-276, lines 35-37

> "because ⃗v −c⃗p⃗s is orthogonal to a scalar multiple of ⃗s, it must be
> orthogonal to ⃗s itself. Then (⃗v −c⃗p⃗s) •⃗s = 0 gives that c⃗p = ⃗v •⃗s/⃗s •⃗s."
> — §VI.1, p. 276, lines 43-45

`closestEq` is the condition `(v − cu)·u = 0`; expanding gives `v·u − c(u·u) = 0`,
hence `c = v·u/(u·u)`, the coefficient in `projEq2`. **ok.**

**The projection is the closest point on the line to v / minimises distance
(`lsEq`, first half).**

> "we can think of the projection ⃗p as being the vector in the line that is
> closest to ⃗v (see Exercise 17)." — §VI.1, p. 277, lines 208-209

> "Let ⃗p be the orthogonal projection of ⃗v ∈Rn onto a line ℓ. Show that ⃗p is
> the point in the line closest to ⃗v." — §VI.1, Exercise 1.17, p. 279,
> lines 403-404

The narration's Pythagoras argument ("moving along the line from the foot only
adds a sideways distance") is the content of that exercise. **ok.**

**Projection generalises to subspaces, with the residual orthogonal and the
result still the closest point; this is the basis of least-squares / best
approximation (`lsEq`, second half).**

> "Let ⃗p be the orthogonal projection of ⃗v ∈Rn onto a subspace S. Show that ⃗p
> is the point in the subspace closest to ⃗v." — §VI.3, Exercise 3.14, p. 291,
> lines 1938-1939

> "For any ⃗v ∈Rn the vector ⃗v −projM(⃗v ) is perpendicular to every vector in
> M." — §VI.3, Lemma 3.7, p. 289-290, lines 1630-1632

The *closest point on a subspace* and *orthogonal residual* claims are therefore
Hefferon's. The explicit identification **least squares = projection** (fitting
scattered data = projecting the observation vector onto the prediction space,
residuals orthogonal, regression as projection) is **not stated in this Topic**;
it is standard linear-algebra fact and is the declared purpose of the Chapter
Five sections for which Hefferon lists this section as a prerequisite:

> "This section is optional. It is a prerequisite only for the ﬁnal two sections
> of Chapter Five, and some Topics." — §VI, p. 275, lines 7-8

The least-squares link is therefore **marked standard**; everything upstream of
it (closest point, orthogonal residual, generalisation to subspaces) is directly
sourced. **ok.**

## Problem s4 — project v=(4,2) onto the x-axis u=(1,0) (`given`, `step1`, `answer`, check)

Our own numbers. u=(1,0) is a unit vector (u·u = 1), so proj = (v·u) u.
v·u = 4·1 + 2·0 = 4, hence proj = 4·(1,0) = (4,0): the x-axis projection keeps
the horizontal part and discards the vertical (cf. Hefferon Example 1.3's axis
projection, p. 276). The gate re-runs `check.expr` `4*1 + 2*0`, `value: 4`,
tol 1%.

```python
import numpy as np
v = np.array([4.0, 2.0]); u = np.array([1.0, 0.0])
vdotu = v @ u; udotu = u @ u
proj = (vdotu/udotu)*u
print("v.u =", vdotu, " u.u =", udotu, " c =", vdotu/udotu)
print("proj =", proj)
print("s4 check '4*1 + 2*0' =", 4*1 + 2*0, "(value 4)")
```

output:
```
v.u = 4.0  u.u = 1.0  c = 4.0
proj = [4. 0.]
s4 check '4*1 + 2*0' = 4 (value 4)
```

proj = (4,0), and `check.expr` `4*1 + 2*0` = 4 = `value`. **Verdict: ok.**

## Problem s5 — project v=(3,1) onto the diagonal u=(1,1) (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own numbers. u=(1,1) is not a unit vector, so the full formula is needed
(exactly as Hefferon's Example 1.2, p. 276). v·u = 3 + 1 = 4, u·u = 2, so
c = 4/2 = 2 and proj = 2·(1,1) = (2,2). The residual v − proj = (1,−1) is
perpendicular to u since (1,−1)·(1,1) = 0 — the defining condition `closestEq`.
The gate re-runs `check.expr` `(3 + 1) / 2`, `value: 2`, tol 1%.

```python
import numpy as np
v = np.array([3.0, 1.0]); u = np.array([1.0, 1.0])
vdotu = v @ u; udotu = u @ u; c = vdotu/udotu
proj = c*u; resid = v - proj
print("v.u =", vdotu, " u.u =", udotu, " c =", c)
print("proj =", proj)
print("residual v-proj =", resid)
print("residual . u =", resid @ u, "(perpendicular)")
print("s5 check '(3 + 1) / 2' =", (3 + 1) / 2, "(value 2)")
```

output:
```
v.u = 4.0  u.u = 2.0  c = 2.0
proj = [2. 2.]
residual v-proj = [ 1. -1.]
residual . u = 0.0 (perpendicular)
s5 check '(3 + 1) / 2' = 2.0 (value 2)
```

proj = (2,2), residual (1,−1) ⊥ u (dot = 0), and `check.expr` `(3 + 1) / 2` = 2
= `value`. **Verdict: ok.**

## Not from Hefferon (our own numbers)

Both worked problems use our own vectors: A projects v=(4,2) onto the x-axis
(u=(1,0)); B projects v=(3,1) onto y=x (u=(1,1)). These are not Hefferon's
worked examples (his §VI.1 projects (2,3) into y=2x, and (x,y,z) onto the
y-axis). The definition and all results — the projection formula (Definition
1.1, p. 276), its derivation from perpendicularity (p. 276), the closest-point
reading (Exercise 1.17, p. 279), and the subspace generalisation (Exercise 3.14
and Lemma 3.7, pp. 289-291) — are Hefferon's, applied to our numbers. The
explicit "least squares = projection" identification is standard and belongs to
the Chapter Five sections this Topic is a prerequisite for.
