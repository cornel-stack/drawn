# Fact-check — LA-16

Primary source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Chapter Three
§V Change of Basis** (local extract
`sources/text/hefferon-linear-algebra/019-change-of-basis.md`, book
pp. 262-273) for: representations varying with the basis, the change-of-basis
matrix as the representation of the identity map (its columns are the new basis
vectors), the conversion lemma `RepB,D(id)·RepB(v) = RepD(v)`, nonsingularity
(hence invertibility) of a change-of-basis matrix, and the map-conversion
formula `ˆH = RepD,ˆD(id)·H·RepˆB,B(id)` which specialises to the similarity
transformation `A' = P^-1 A P`. Both worked problems use our own shear basis
(b1=(1,0), b2=(1,1), P=[[1,1],[0,1]]) and vector v=(3,2); the numbers are ours,
the method is Hefferon's.

## The central claims

**A vector's coordinates are relative to a basis; the same vector has different
representations in different bases (`coordNote`).**

> "Representations vary with the bases. For instance, with respect to the bases
> E2 and B = ⟨(1,1),(1,−1)⟩ ⃗e1 ∈R2 has these diﬀerent representations.
> RepE2(⃗e1) = (1,0)   RepB(⃗e1) = (1/2,1/2)." — §V, p. 262, lines 7-30

The one arrow e1 has two coordinate pairs, exactly as `coordNote` writes v as
(3,2)_std and (1,2)_B. The underlying vector is unchanged:

> "In converting RepB(⃗v) to RepD(⃗v) the underlying vector ⃗v doesn't change."
> — §V.1, p. 262, line 51

**ok.**

**The change-of-basis matrix P has the new basis vectors as its columns, and
converts coordinates between bases; v_std = P [v]_B (`changeEq`).**

> "1.1 Deﬁnition The change of basis matrix for bases B, D ⊂V is the
> representation of the identity map id: V →V with respect to those bases.
> RepB,D(id) = [ ... RepD(⃗β1) · · · RepD(⃗βn) ... ]" — §V.1, Definition 1.1,
> p. 262, lines 61-78

Its columns are the B-basis vectors represented in D; when D is the standard
basis those columns are simply the new basis vectors in standard coordinates:

> "ﬁnd the eﬀect of the identity matrix on the starting basis ˆB — which is no
> eﬀect at all — and then represent those basis elements with respect to the
> ending basis E2. RepˆB,E2(id) = [[1,0],[1,2]] ... This calculation is easy when
> the ending basis is the standard one." — §V.2, Example 2.2, p. 269, lines
> 825-836

The conversion itself is Lemma 1.3:

> "1.3 Lemma To convert from the representation of a vector ⃗v with respect to B
> to its representation with respect to D use the change of basis matrix.
> RepB,D(id) RepB(⃗v) = RepD(⃗v)." — §V.1, Lemma 1.3, p. 263, lines 85-87

With D the standard basis this reads v_std = P [v]_B. **ok.**

**[v]_B = P^-1 v_std — invert to go the other way (`invEq`).** The change-of-basis
matrix is nonsingular, hence invertible:

> "1.5 Lemma A matrix changes bases if and only if it is nonsingular." — §V.1,
> Lemma 1.5, p. 264, lines 182

and the reverse conversion is done by the inverse:

> "we could instead calculate it as the inverse of the matrix for going up
> Rep ˆD,E2(id)." — §V.2, Example 2.2, p. 268-269, lines 839-843

So if P = RepB,E2(id) carries [v]_B to v_std, then P^-1 carries v_std back:
[v]_B = P^-1 v_std. **ok.**

**A' = P^-1 A P — a map's matrix transforms by similarity under a change of
basis (`simEq`).**

> "2.1 Theorem To convert from the matrix H representing a map h with respect to
> B, D to the matrix ˆH representing it with respect to ˆB, ˆD use this formula.
> ˆH = RepD, ˆD(id) · H · RepˆB,B(id)." — §V.2, Theorem 2.1, p. 267, lines 743-746

For a transformation represented with the same starting and ending basis, the
two outer change-of-basis factors are inverses, giving ˆH = P^-1 H P. Hefferon
names this case:

> "Square matrices are similar if they represent the same transformation, but
> each with respect to the same ending as starting basis. That is, RepB1,B1(t)
> is similar to RepB2,B2(t)." — §V.2, Exercise 2.32, p. 273, lines 1924-1926

The right-to-left reading of the sandwich is stated in Example 2.2:

> "the matrix multiplication reads right to left, as the three functions are
> composed and function composition reads right to left." — §V.2, p. 269, lines
> 823-824

and the diagonalisation payoff the narration points to is Example 2.3 (p.
269-270, lines 948-1032): the map [[0,1,1],[1,0,1],[1,1,0]] becomes diag(−1,−1,2)
in a suitable basis. **ok.**

**The vector / map is unchanged; only its representation changes
(`coordNote`, `simEq` narration).**

> "In converting RepB(⃗v) to RepD(⃗v) the underlying vector ⃗v doesn't change."
> — §V.1, p. 262, line 51

> "The matrix is messier but the map that it represents is the same." — §V.2,
> Example 2.2, p. 269, line 877

**ok.**

## Problem s4 — find [v]_B for b1=(1,0), b2=(1,1), v=(3,2) (`given`, `step1`, `step2`, `answer`, check)

Our own numbers. The coordinates of v in basis B are the weights (a,b) with
a·(1,0)+b·(1,1)=(3,2) (representation definition; Lemma 1.3, p. 263). The system
is a+b=3, b=2, so b=2 and a=3−2=1, giving [v]_B=(1,2). The gate re-runs
`check.expr` `3 - 2`, declared `value: 1`, tol 1%.

```python
import numpy as np
P = np.array([[1,1],[0,1]], float)   # columns are b1=(1,0), b2=(1,1)
v = np.array([3,2], float)
coords = np.linalg.solve(P, v)
print("np.linalg.solve([[1,1],[0,1]],[3,2]) =", coords)
print("s4 check expr '3 - 2' =", 3 - 2, " (value 1)")
```

output:
```
np.linalg.solve([[1,1],[0,1]],[3,2]) = [1. 2.]
s4 check expr '3 - 2' = 1  (value 1)
```

[v]_B = (1,2), and `check.expr` `3 - 2` = 1 = `value`. **Verdict: ok.**

## Problem s5 — recover v_std from [v]_B=(1,2) (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own numbers (the reverse of s4). Forming the combination 1·(1,0)+2·(1,1) —
equivalently P·[1,2] — gives (1+2, 0+2) = (3,2), exactly the vector s4 started
from (v_std = P [v]_B; Lemma 1.3, p. 263). The gate re-runs `check.expr`
`1*1 + 2*1`, declared `value: 3`, tol 1% (the first component).

```python
import numpy as np
P = np.array([[1,1],[0,1]], float)
b1 = np.array([1,0], float)
b2 = np.array([1,1], float)
vstd = 1*b1 + 2*b2
print("1*[1,0] + 2*[1,1] =", vstd)
print("P @ [1,2] =", P @ np.array([1,2], float))
print("s5 check expr '1*1 + 2*1' =", 1*1 + 2*1, " (value 3, first component)")
```

output:
```
1*[1,0] + 2*[1,1] = [3. 2.]
P @ [1,2] = [3. 2.]
s5 check expr '1*1 + 2*1' = 3  (value 3, first component)
```

v_std = (3,2), and `check.expr` `1*1 + 2*1` = 3 = `value`. **Verdict: ok.**

## Not from Hefferon (our own numbers)

Both worked problems use our own shear basis b1=(1,0), b2=(1,1) (so
P=[[1,1],[0,1]]) and vector v=(3,2). These are not Hefferon's worked examples
(his §V uses B=⟨(2,1),(1,0)⟩, D=⟨(−1,1),(1,1)⟩ in Example 1.4 and the π/6
rotation in Example 2.2). The definitions and results — the change-of-basis
matrix with basis vectors as columns (Definition 1.1, p. 262), the conversion
lemma RepB,D(id)·RepB(v)=RepD(v) (Lemma 1.3, p. 263), nonsingularity/invertibility
(Lemma 1.5, p. 264), and the map-conversion/similarity formula (Theorem 2.1,
p. 267; Exercise 2.32, p. 273) — are all Hefferon's, applied to our numbers.
