# Fact-check — LA-07

Primary source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Topic: Geometry
of Linear Maps**, local extract
`sources/text/hefferon-linear-algebra/022-topic-geometry-of-linear-maps.md`
(book pp. 302-307). That topic supplies the *geometric* picture the lesson
rests on — linear maps act regularly, spreading the domain by the same factor
everywhere (p. 302, lines 36-41), and are built from dilations, shears,
reflections and projections, each 'acts in a simple way' (p. 304, lines 265-269)
— but the precise algebraic facts the board items state live in three
neighbouring sections of the same book, cited per item:

- **§II Homomorphisms** `016-homomorphisms.md` — definition of linear map, the
  map is determined by its action on a basis.
- **§III Computing Linear Maps** `017-computing-linear-maps.md` — columns are
  the images of the basis vectors, and the matrix-vector product.
- **Chapter Four §II Geometry of Determinants** `027-geometry-of-determinants.md`
  — the determinant as the area-scaling factor.

The lesson explains the material in its own words; both worked problems use our
own numbers.

## Theory — the four board claims the lesson is built on

**A linear map is determined by its action on a basis.**

> "A homomorphism is determined by its action on a basis: if V is a vector space
> with basis ⟨β1, ..., βn⟩, ... then there exists a homomorphism from V to W
> sending each βi to wi, and that homomorphism is unique." — §II, Theorem 1.9,
> `016-homomorphisms.md`, p. 193, lines 330-333

> "The prior section shows that a linear map is determined by its action on a
> basis. The equation h(v) = h(c1·β1 + ··· + cn·βn) = c1·h(β1) + ··· + cn·h(βn)
> describes how we get the value of the map on any vector v ..." — §III,
> `017-computing-linear-maps.md`, p. 212, lines 7-11

This is the narration's claim that the map "is fixed entirely by where the two
basis vectors land". Example 1.11 (p. 194, lines 357-411) does it concretely for
a map R2→R2 given only on the standard basis.

**The matrix columns are the images of the basis vectors (`matA`).**

> "we make it by adjoining the vectors representing the h(βi)'s." — §III,
> `017-computing-linear-maps.md`, p. 213, lines 379-394

> "RepB,D(h) = [h1,1 ... h1,n; ...; hm,1 ... hm,n] ... is the matrix
> representation of h" built from the columns RepD(h(β1)), ..., RepD(h(βn)). —
> §III, Definition 1.2, p. 214, lines 397-464

With the standard basis "vector representation is transparent — the
representation of v is v" (§III.2, p. 227, lines 2009-2013), so col 1 = t(e1),
col 2 = t(e2). The rotation Example 1.10 (p. 217-218) is the cleanest instance:
e1 ↦ (cos θ, sin θ), e2 ↦ (−sin θ, cos θ), adjoined into the rotation matrix.
Our `matA` A = [[2,1],[1,2]] with legend "col 1 = where i-hat lands, col 2 =
where j-hat lands" is exactly this. **ok.**

**The matrix-vector product (`mvEq`, `colEq`).**

> "The matrix-vector product of a m×n matrix and a n×1 vector is ... = [a11 c1 +
> ··· + a1n cn; ...; am1 c1 + ··· + amn cn]." — §III, Definition 1.6,
> `017-computing-linear-maps.md`, p. 215, lines 650-701

At 2×2 this is A[x;y] = [ax+by; cx+dy] (`mvEq`); the same map appears as
"(x,y) ↦ (ax+by, cx+dy)" in Exercise 2.41(b) (§II, p. 202, lines 1385-1394).
The column reading (`colEq`):

> "= c1[h11;...;hm1] + ··· + cn[h1n;...;hmn] ... The result is the columns of the
> matrix weighted by the entries of the vector." — §III, p. 219, lines 1203-1296

So A[x;y] = x[a;c] + y[b;d]. **ok.**

**Linearity (`linEq`).**

> "A function between vector spaces h: V → W that preserves addition if v1,v2 ∈ V
> then h(v1+v2) = h(v1) + h(v2) and scalar multiplication if v ∈ V and r ∈ R then
> h(r·v) = r·h(v) is a homomorphism or linear map." — §II, Definition 1.1,
> `016-homomorphisms.md`, p. 191, lines 16-20

Our `linEq` A(u+v) = Au + Av is the addition half; the scalar half t(cv)=c·t(v)
is the second clause, and the combined form is Lemma 1.7(2), p. 193, lines
254-257. The narration's "the grid stays straight, parallel and evenly spaced"
is the geometric reading of linearity from the primary topic (p. 302, lines
36-41). The origin is fixed:

> "A linear map sends the zero vector to the zero vector." — §II, Lemma 1.6,
> `016-homomorphisms.md`, p. 193, line 253

**det = 0 ⇔ singular ⇔ the plane collapses to a line.** The narration's claim
that "if the determinant is zero ... the transformation has flattened the plane
onto a line — which is the geometric meaning of a matrix with no inverse":

> "A linear map that is one-to-one and onto is nonsingular, otherwise it is
> singular." — §III, Definition 2.7, `017-computing-linear-maps.md`, p. 227,
> lines 2094-2097

> "a matrix represents isomorphisms if and only if it is square and
> nonsingular." — §III, Lemma 2.9, p. 227, lines 2105-2108

and in determinant terms (the collapse of the box to zero area):

> "if |T| = 0 then |TS| = 0." — Ch. 4 §II.1, Theorem 1.5 proof,
> `027-geometry-of-determinants.md`, p. 358, line 175

det = 0 means the box (image of the unit square) has zero size, i.e. the columns
are linearly dependent and the image is a line (or point). **All ok.**

## Determinant as the factor by which area scales

The lesson's central quantitative claim — "the determinant is the factor by
which the transformation scales every area" — is **Theorem 1.5 in the Geometry
of Determinants section, not in the lesson's primary Geometry-of-Linear-Maps
topic.** Cited from `027-geometry-of-determinants.md` per the review brief:

> "A transformation t: Rn → Rn changes the size of all boxes by the same factor,
> namely, the size of the image of a box |t(S)| is |T| times the size of the box
> |S|, where T is the matrix representing t with respect to the standard basis."
> — Ch. 4 §II.1, Theorem 1.5, `027-geometry-of-determinants.md`, p. 358, lines
> 161-164

> "That the area equals the value of the determinant |x1 x2; y1 y2| = x1 y2 −
> x2 y1 is no coincidence." — Ch. 4 §II.1, p. 355-356, lines 56-62

> "The volume of a box is the absolute value of the determinant of a matrix with
> those vectors as columns." — Ch. 4 §II.1, Definition 1.3, p. 357, lines 129-130

Example 1.6 (p. 358-359, lines 188-216) is directly parallel to the lesson's
diagram: a matrix with determinant computed from the box |2 1; 1 2| = 3 doubles
areas (its own matrix has det 2). The lesson's s2 diagram uses exactly A =
[[2,1],[1,2]], whose determinant is 3 (confirmed below), matching Hefferon's
"|2 1; 1 2| = 3" on p. 358, line 203. **ok.**

## Problem s4 — apply A=[[2,1],[1,3]] to v=(1,2) (`given`, `step1`, `step2`, `answer`, check)

Our own matrix and vector. Column combination (§III column view) gives `step1`;
entry-by-entry (Def 1.6) gives `step2`; the boxed `answer` is (4,7). The gate
re-runs `check.expr` `2*1 + 1*2`, declared `value: 4` (the x-component), tol 1%.

```python
import numpy as np
A = np.array([[2,1],[1,3]]); v = np.array([1,2])
print("A @ v =", A @ v)
print("s4 check expr 2*1 + 1*2 =", 2*1 + 1*2)
```

output:
```
A @ v = [4 7]
s4 check expr 2*1 + 1*2 = 4
```

So Av = (4,7): top = 2(1)+1(2) = 4, bottom = 1(1)+3(2) = 7. `check.expr` returns
4, matching `value: 4`. **Verdict: ok.**

## Problem s5 — area scaling by A=[[3,1],[1,2]] (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own matrix and starting area 2. The scaling factor is det A = 3(2)−1(1) = 5
(§II.1 area formula, `step1b`); new area = |det A|·area_0 = 5·2 (Theorem 1.5,
`step2b`); boxed `answer2` = 10. The gate re-runs `check.expr` `(3*2 - 1*1) * 2`,
declared `value: 10`, tol 1%.

```python
import numpy as np
B = np.array([[3,1],[1,2]])
print("det B =", np.linalg.det(B))
print("s5 check expr (3*2 - 1*1) * 2 =", (3*2 - 1*1) * 2)
# s2 diagram matrix:
C = np.array([[2,1],[1,2]])
print("det C (s2 diagram) =", np.linalg.det(C))
```

output:
```
det B = 5.000000000000001
s5 check expr (3*2 - 1*1) * 2 = 10
det C (s2 diagram) = 2.9999999999999996
```

So det A = 5.0, new area = 5×2 = 10. `check.expr` returns 10, matching
`value: 10`. The s2 diagram matrix [[2,1],[1,2]] has determinant 3.0 (the "area
three" parallelogram in the narration), matching Hefferon's |2 1; 1 2| = 3.
**Verdict: ok.**
