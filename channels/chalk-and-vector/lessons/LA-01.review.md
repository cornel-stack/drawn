# Fact-check — LA-01

Source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), §1.I Solving Linear
Systems / Gauss's Method and §1.II Linear Geometry. Local extracts:
`sources/text/hefferon-linear-algebra/001-solving-linear-systems.md` and
`002-linear-geometry.md`. Our lesson explains the material in its own words; the
checks below cite the specific source location that licenses each claim.

## Equation `eq1` — `2x - y = 3`

A first-degree, single-power-per-unknown equation. This is exactly Hefferon's
definition of a linear equation:

> "A linear equation in the variables x1, . . . , xn has the form a1x1 + a2x2 +
> a3x3 + · · · + anxn = d where d ∈ R is the constant." — §1.I.1, Def 1.1, p. 2

The narration's gloss ("each unknown appears only on its own, to the first
power — no squares, no products, no sines") restates Def 1.1 / Example 1.2:

> "The combination 3x1 + 2x2 of x1 and x2 is linear. The combination 3x1^2 + 2x2
> is not a linear function ... nor is 3x1 + 2 sin(x2)." — §1.I.1, Example 1.2, p. 2

This specific equation is the first line of Hefferon's own row-picture example:

> "Unique solution — 3x + 2y = 7, x − y = −1" — §1.II Linear Geometry, p. 35

**Verdict: ok** — standard linear equation per Def 1.1; our coefficients differ
from Hefferon's example but are a valid instance of the same form.

## Equation `eq2` — `x + y = 3`

Second equation of the same 2×2 system; same justification as `eq1` (Def 1.1,
p. 2). Paired with `eq1` it forms a "system of linear equations" per Def 1.1:

> "A system of linear equations a1,1x1 + · · · = d1 ... am,1x1 + · · · = dm has
> the solution (s1, . . . , sn) if that n-tuple is a solution of all of the
> equations." — §1.I.1, Def 1.1, p. 2

**Verdict: ok.**

### Row-picture claims in s2 (standard restatements, sourced to §1.II)

The narration's row picture — each equation is a line, a solution lies on both
lines, two non-parallel lines meet in one point, and the three alternatives
(unique / none / infinitely many) — is Hefferon's §1.II opening verbatim in
substance:

> "Draw each two-unknowns equation as a line in the plane and then the two lines
> could have a unique intersection, be parallel, or be the same line."
> — §1.II Linear Geometry, p. 35

> "Unique solution ... No solutions ... Infinitely many solutions" (three
> labelled line pictures) — §1.II, p. 35

The "only three types of solution sets — singleton, empty, and infinite" is also
stated explicitly (§1.II, p. 35) and proved in §1.I (summary, p. 8-9). This is a
standard textbook restatement, not invented.

## Equation `vecEq` — `x(2,1) + y(-1,1) = (3,3)`

The column picture writes the system as a linear combination of its coefficient
columns equal to the right-hand-side vector. Hefferon defines the two operations
this rests on:

> "The vector sum of u and v is the vector of the sums." — §1.I.2, Def 2.10, p. 17

> "The scalar multiplication of the real number r and the vector v is the vector
> of the multiples: r·v = (rv1, …, rvn)." — §1.I.2, Def 2.11, p. 17-18

and gives these operations a geometric reading (displacement arrows, tip-to-tail
addition, scaling):

> "if v represents a displacement then 3v represents a displacement in the same
> direction but three times as far ... v + w represents those displacements"
> — §1.II.1 Vectors in Space, pp. 36-37

**Note / standard restatement.** Hefferon uses column vectors to *describe
solution sets* (§1.I.2, Example 2.13; Def 2.8 column vector, p. 16) and builds
the geometry of vector addition/scaling in §1.II.1, but this extract does not
state the specific "columns of the coefficient matrix combine to reach b" framing
of a 2×2 system. That framing (the "column picture") is a standard restatement of
Def 2.10-2.11 applied to the coefficient columns — it is textbook-standard, not
invented. The numerical content is verified below (column picture lands on b).

**Verdict: ok** (sourced to Def 2.10-2.11 + §1.II.1; column-picture framing is a
standard restatement; numerics confirmed).

## Equation `elim` — `2(x+y) - (2x - y) = 2(3) - 3  =>  3y = 3`

A single row-combination step (add a multiple of one equation to another),
licensed by Gauss's Method operation (3):

> "If a linear system is changed to another by one of these operations ... (3)
> an equation is replaced by the sum of itself and a multiple of another then
> the two systems have the same set of solutions." — §1.I.1, Thm 1.5, p. 4

> "The three operations from Theorem 1.5 are the elementary reduction
> operations, or row operations ... swapping, multiplying by a scalar ..., and
> row combination." — §1.I.1, Def 1.6, p. 5

Pattern matches Example 1.7's `-2rho_1 + rho_2` elimination of a leading term
(§1.I.1, p. 5). **Verdict: ok.** Arithmetic: 2·(x+y) − (2x − y) = 3y, and
2·3 − 3 = 3, so 3y = 3, y = 1 — correct.

## Equation `back` — `x + y = 3  =>  x = 2`

Back-substitution of the found value into a remaining equation:

> "The bottom equation shows that x3 = 3. Substituting 3 for x3 in the middle
> equation shows that x2 = 1. Substituting those two into the top equation gives
> that x1 = 3." — §1.I.1, Example 1.4, p. 3

With y = 1: x + 1 = 3 so x = 2. **Verdict: ok.**

## Equation `soln` — `(x, y) = (2, 1)`

Unique-solution conclusion of the in-lesson system. Hefferon's Example 1.4 ends
the same way ("the system has a unique solution; the solution set is {(3,1,3)}",
p. 3). Verified numerically for our system:

```python
import numpy as np
print(np.linalg.solve([[2,-1],[1,1]],[3,3]))
```
output:
```
[2. 1.]
```

**Verdict: ok** — solution is exactly (2, 1).

### Column-picture numeric confirmation (s3)

The claim "take two of the first column and one of the second, laid tip to tail,
and they land exactly on the target (3, 3)":

```python
import numpy as np
print(2*np.array([2,1]) + 1*np.array([-1,1]))
```
output:
```
[3 3]
```

So x·(2,1) + y·(-1,1) with (x, y) = (2, 1) equals (3, 3). The column picture and
the row picture give the same solution. **Confirmed.**

## Equation `given` — `x + y = 2,  2x - y = -5`

The worked-problem system (s5). A system of two linear equations per Def 1.1
(p. 2); read geometrically as two lines in the plane per §1.II (p. 35). Verified
numerically:

```python
import numpy as np
print(np.linalg.solve([[1,1],[2,-1]],[2,-5]))
```
output:
```
[-1.  3.]
```

**Verdict: ok** — a consistent 2×2 system with unique solution (-1, 3).

## Equation `step1` — `(2x - y) - 2(x + y) = -5 - 2(2)`

Row-combination step eliminating x (subtract twice equation 1 from equation 2),
licensed by Thm 1.5 op (3) / Def 1.6 (§1.I.1, pp. 4-5), matching Example 1.7's
`-2rho_1 + rho_2` (p. 5). **Verdict: ok.** Arithmetic: (2x − y) − 2(x + y) = −3y,
and −5 − 2·2 = −9, so −3y = −9.

## Equation `step2` — `-3y = -9  =>  y = 3`

Solving the reduced single-unknown equation (rescale by a nonzero constant, Thm
1.5 op (2) / Def 1.6, p. 4-5; read-off as in Example 1.4, p. 3). −9 / −3 = 3.
**Verdict: ok.**

## Equation `step3` — `x + 3 = 2  =>  x = -1`

Back-substitution of y = 3 into equation 1, as in Example 1.4 (p. 3). 2 − 3 = −1.
**Verdict: ok.**

## Equation `answer` — `(x, y) = (-1, 3)`

Unique-solution conclusion of the worked problem; matches Hefferon's

**Verdict: ok.**

### s4 narration — row operations and Gauss's method

The three operations and the "never gains or loses a solution, each reversible"
claims are Hefferon's Thm 1.5 and Def 1.6 directly:

> "(1) an equation is swapped with another (2) an equation has both sides
> multiplied by a nonzero constant (3) an equation is replaced by the sum of
> itself and a multiple of another ... the two systems have the same set of
> solutions." — §1.I.1, Thm 1.5, p. 4

> "Gauss's Method never loses solutions nor does it ever pick up extraneous
> solutions." — §1.I.1, p. 3

Reversibility is Exercise 1.36 ("Prove that each operation of Gauss's Method is
reversible", p. 12). "Always terminates / drives to triangular (echelon) form" is
Def 1.10 and the summary (§1.I.1, pp. 5, 8-9). Standard restatements, sourced.

## Problem `s5`

```python
import numpy as np
# worked problem: x + y = 2, 2x - y = -5
print(np.linalg.solve([[1, 1], [2, -1]], [2, -5]))
# boxed first component (check expr):
print(np.linalg.solve([[1, 1], [2, -1]], [2, -5])[0])
```

output:
```
[-1.  3.]
-1.0
```

The boxed answer (x, y) = (-1, 3) is exact. The gate's `check:` expr
`np.linalg.solve([[1, 1], [2, -1]], [2, -5])[0]` returns -1.0, matching the
declared value -1.0 within tol 0.01. **Verdict: ok.**
