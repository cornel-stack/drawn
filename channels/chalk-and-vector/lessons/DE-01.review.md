# Fact-check — DE-01

Source: OpenStax, *Calculus Volume 2* (CC BY 4.0), §4.1 Basics of Differential
Equations. Local extract:
`sources/text/openstax-calculus-vol2/036-4-1-basics-of-differential-equations.md`
(PDF pp. 308-316 / book pp. 308-316). Our lesson explains the material in its
own words; each entry below cites the specific source location that licenses the
claim.

**Extraction note.** The text extraction dropped all inline/display LaTeX from
§4.1 — every mathematical expression in the source appears as a *gap* between
prose lines (e.g. the definition reads "an equation involving an unknown
function  and one or more of its derivatives", with the symbol for the function
missing). This is the same situation as the OpenStax image-equation convention
noted elsewhere. Consequently, for each equation item below I cite the
**surrounding prose** that states the claim in words, and I verify every
symbolic/numeric equality independently in Python (sympy) rather than
character-matching the missing LaTeX.

**Originality note.** The specific constants in this lesson are *not* copied from
any source example. OpenStax Example 4.1 verifies `y=e^{-3x}+2x+...`-type
functions, Example 4.3 uses a different constant, and Example 4.5 is a `y'=...`
antiderivative problem. Our chosen numbers — `k=½` (s3), `k=2` with `y(0)=3`
(s4), and the worked problem `y'=3y, y(0)=5` (s6) — are fresh instances of the
same standard forms, adapted with changed numbers per the house rule.

## Equation `genForm` — `F(x, y, y', y'', …) = 0`

The general-form statement that a differential equation relates an unknown
function to one or more of its derivatives:

> "A differential equation is an equation involving an unknown function  and one
> or more of its derivatives. A solution to a differential equation is a function
>  that satisfies the differential equation when  and its derivatives are
> substituted into the equation." — §4.1, Definition, p. 308

Writing this implicit relation as `F(x, y, y', y'', …) = 0` is the standard
symbolic shorthand for exactly that definition. **Verdict: ok.**

## Equation `propRate` — `y' = k y`

The lesson's simplest example: rate of change proportional to current amount.
§4.1 introduces DEs through "Start with some function and take its derivative.
The answer must be equal to …" (p. 308) and develops the general solution of
this very equation under "General and Particular Solutions" (p. 309, where the
general solution is the exponential family — the exact companion of `y'=ky`). The
first-order order claim matches:

> "The order of a differential equation is the highest order of any derivative of
> the unknown function that appears in the equation." — §4.1, Definition, p. 309

`y'=ky` contains only the first derivative, so it is first order. **Verdict: ok.**

## Equation `halfK` — `y' = ½ y`

A concrete instance of `y'=ky` with `k=½`, used to make the "slope equals half
the height" reading vivid. Same source basis as `propRate` (§4.1, pp. 308-309);
the DE-as-slope-rule reading is the source's "take its derivative; the answer
must be equal to …" framing (p. 308). The constant ½ is ours, not the source's.
Numerics in the narration: at the marked point the exponential `e^x` has height
`e ≈ 2.718`, and under `y'=½y` the slope there would be `½·2.718 ≈ 1.36` ("about
one and a third"). (Note the lesson plots `y=e^x` for all three diagram scenes
and uses `halfK` only as an illustrative slope rule; the "about 2.7 high, slope
about 1.3" statement is internally consistent with ½·e.) **Verdict: ok.**

## Equation `genSol` — `y = C e^{kx}`

The general solution of `y'=ky`:

> "any function of the form … where  represents any constant, is a solution as
> well. The reason is that the derivative of … is … regardless of the value of …
> It can be shown that any solution of this differential equation must be of the
> form … This is an example of a general solution to a differential equation."
> — §4.1, "General and Particular Solutions", p. 309

That `y=Ce^{kx}` satisfies `y'=ky` for every C is confirmed symbolically below.
**Verdict: ok.**

## Equation `verify` — `y = Ce^{2x} ⟹ y' = 2Ce^{2x} = 2y`

A concrete verification (k=2) by the chain rule, exactly the method of:

> "To verify the solution, we first calculate … using the chain rule for
> derivatives. … Next we substitute  and … into the left-hand side of the
> differential equation" — §4.1, Example 4.1, p. 308

Verified symbolically below (`y'-2y = 0`). **Verdict: ok.**

## Equation `particular` — `y(0) = 3 ⟹ C = 3 ⟹ y = 3e^{2x}`

Fixing the arbitrary constant from an initial condition:

> "A particular solution can often be uniquely identified if we are given
> additional information" (p. 309); "to determine the value of C, we substitute
> the values … and solve for C" — §4.1, Example 4.3, pp. 309-310

With `y=Ce^{2x}`, `y(0)=C`, so `C=3` and `y=3e^{2x}`. Confirmed symbolically
below. **Verdict: ok.**

## Equation `newton` — `F = ma = m v' ⟹ v' = -g`

Newton's second law as a DE, and the mass-independence of free fall:

> "Newton's second law of motion (in equation form F=ma, where  represents
> force,  represents mass, and  represents acceleration)" — §4.1, p. 312

> "Acceleration is the derivative of velocity, so …" and "this force must be
> equal to the force of gravity …, which … is given by …, since this force acts
> in a downward direction. Therefore we obtain the equation …, which becomes …
> Dividing both sides of the equation by  gives the equation …" — §4.1, p. 312

> "Notice that this differential equation remains the same regardless of the mass
> of the object." — §4.1, p. 312

> "It is worth noting that the mass of the ball cancelled out completely in the
> process of solving the problem." — §4.1, Example 4.7, p. 314

The source's acceleration/velocity sign convention gives `v' = -g` (gravity
downward); our `F=ma=mv' ⟹ v'=-g` reproduces this exactly. **Verdict: ok.**

## Equation `given` — `y' = 3y, y(0) = 5`

The worked-problem statement (s6): a first-order growth DE with one initial
value — an initial-value problem per:

> "A differential equation together with one or more initial values is called an
> initial-value problem. The general rule is that the number of initial values
> needed … is equal to the order of the differential equation." — §4.1,
> "Initial-Value Problems", p. 310

First order ⟹ one initial value, satisfied by `y(0)=5`. The constants `3` and `5`
are ours (not a verbatim source example). **Verdict: ok.**

## Equation `step2` — `y(0) = C = 5`

## Equation `answer` — `y = 5 e^{3x}`

## Symbolic verification (sympy)

```python
import sympy as sp
import numpy as np

x, k, C = sp.symbols('x k C')

# genSol: y = C e^{kx} satisfies y' = k y
y = C*sp.exp(k*x)
print("1) y'=k y residual:", sp.simplify(sp.diff(y, x) - k*y))

# verify / step1: y = C e^{2x} gives y' = 2y
y2 = C*sp.exp(2*x)
print("2) y'-2y residual:", sp.simplify(sp.diff(y2, x) - 2*y2))

# particular: y(0)=3 => C=3
print("3) y(0) for C e^{kx}:", y.subs(x,0), "-> set =3 => C =", sp.solve(sp.Eq(y.subs(x,0),3), C))

# worked problem s6: y'=3y, y(0)=5 => y = 5 e^{3x}
f = sp.Function('f')
sol = sp.dsolve(sp.Eq(f(x).diff(x), 3*f(x)), f(x), ics={f(0):5})
print("4) dsolve y'=3y, y(0)=5:", sol)
```

output:
```
1) y'=k y residual: 0
2) y'-2y residual: 0
3) y(0) for C e^{kx}: C -> set =3 => C = [3]
4) dsolve y'=3y, y(0)=5: Eq(f(x), 5*exp(3*x))
```

So `y=Ce^{kx}` satisfies `y'=ky` identically; `y=Ce^{2x}` gives `y'=2y`; the
condition `y(0)=3` forces `C=3`; and the full IVP `y'=3y, y(0)=5` has the unique
solution `y=5e^{3x}` (matching the boxed `answer`). **All confirmed.**
