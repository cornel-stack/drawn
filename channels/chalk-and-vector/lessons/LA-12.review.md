# Fact-check — LA-12

Primary sources: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Chapter Three
§II Homomorphisms** (local extract
`sources/text/hefferon-linear-algebra/016-homomorphisms.md`, book pp. 201-221)
for the definitions of range space, rank, null space, nullity and the
rank-nullity theorem; and **Chapter Three §III Computing Linear Maps**
(`017-computing-linear-maps.md`, book pp. 222-241 — the file the lesson cites)
for the identification of a matrix's rank with the dimension of its column
space, and for the nonsingular/singular (full-rank / nullity-0) characterisation.
The lesson YAML cites §III pp. 200-224; the formal rank-nullity machinery
actually lives in the neighbouring §II Homomorphisms file, so both files are
cited below. Both worked problems use our own numbers, adapted from §III
Exercise 2.21/2.22 (Problem A) and §II Exercise 2.25 (Problem B).

## The central claims

**rank = dimension of the image / range space / column space (`rankEq`,
`rankEq2`).**

> "The range space of a homomorphism h: V -> W is R(h) = {h(v) | v in V},
> sometimes denoted h(V). The dimension of the range space is the map's rank."
> — §II, Definition 2.2, p. 204, lines 823-825

> "The rank of the map h is the dimension of this range space. The rank of the
> matrix is the dimension of its column space, the span of the set of its
> columns ... the size of the largest linearly independent subset of the range
> space equals the size of the largest linearly independent subset of the column
> space, and so the two spaces have the same dimension." — §III, Theorem 2.4
> proof, p. 225-226, lines 2029-2043

So rank = dim(image) = dim(column space) = number of linearly independent
columns. **ok.**

**nullity = dimension of the null space / kernel (`nullEq`).**

> "The null space or kernel of a linear map h: V -> W is the inverse image of
> 0_W. N(h) = h^{-1}(0_W) = {v in V | h(v) = 0_W}. The dimension of the null
> space is the map's nullity." — §II, Definition 2.11, p. 204, lines 1053-1056

Our `nullEq` = dim{x : A x = 0} is exactly this (A for h, 0 for 0_W). **ok.**

**The rank-nullity theorem: rank + nullity = dim(domain) = number of columns
(`rntEq`, `step2`, `step1b`, `step2b`).**

> "A linear map's rank plus its nullity equals the dimension of its domain."
> — §II, Theorem 2.14, p. 205, lines 1085-1086

For an m x n matrix the domain dimension is the number of columns n:

> "In that matrix the number of columns n is the dimension of the map's domain
> while the number of rows m is the dimension of the codomain." — §III,
> Definition 1.2, p. 214, lines 465-466

So rank + nullity = n. **ok.**

**Full rank <=> nullity 0 <=> invertible (nonsingular); det 0 <=> singular <=>
nullity > 0.**

> "The rank of a linear map is less than or equal to the dimension of the domain.
> Equality holds if and only if the nullity of the map is 0." — §II, Corollary
> 2.17, p. 206, lines 1165-1166

> "Where V is an n-dimensional vector space, these are equivalent statements
> about a linear map h: V -> W. (1) h is one-to-one ... (3) N(h) = {0}, that is,
> nullity(h) = 0 (4) rank(h) = n" — §II, Theorem 2.20, p. 206-207, lines
> 1210-1215

> "A linear map that is one-to-one and onto is nonsingular, otherwise it is
> singular. ... A square matrix represents nonsingular maps if and only if it is
> a nonsingular matrix." — §III, Definition 2.7 / Lemma 2.9, p. 227, lines
> 2094-2095, 2105-2108

So a full-rank square matrix has nullity 0 and is invertible (one-to-one and
onto). A singular square matrix (det 0) fails one-to-one, so by Theorem 2.20 its
nullity is not 0. The det = 0 <=> singular <=> nullity > 0 chain is standard
(Hefferon defines "nonsingular" = unique-solution coefficient matrix, p. 227,
lines 2102-2104) and matches Problem A below (det 0, rank 1, nullity 1). **ok.**

## Problem s4 — rank and nullity of A = [[1,2],[2,4]] (`given`, `step1`, `step2`, `answer`, check)

Our own matrix, adapted from §III Exercise 2.21/2.22 (p. 229-230). Row 2 = 2 *
row 1, so rank 1 (`step1`); nullity = n - rank = 2 - 1 (`step2`) = 1 (`answer`);
det = 1*4 - 2*2 = 0 confirms singular. The gate re-runs `check.expr` `2 - 1`,
declared `value: 1`, tol 1%.

```python
import numpy as np
A = np.array([[1,2],[2,4]], float)
r = np.linalg.matrix_rank(A)
n = A.shape[1]
print("matrix_rank(A)      =", r)
print("n (columns)         =", n)
print("nullity = n - rank  =", n - r)
print("det(A) = 1*4 - 2*2  =", np.linalg.det(A))
print("row2 == 2*row1?     =", np.allclose(A[1], 2*A[0]))
print("s4 check '2 - 1'    =", 2 - 1)
```

output:
```
matrix_rank(A)      = 1
n (columns)         = 2
nullity = n - rank  = 1
det(A) = 1*4 - 2*2  = 0.0
row2 == 2*row1?     = True
s4 check '2 - 1'    = 1
```

rank 1, nullity 1, det 0 (singular), and row2 = 2*row1. `check.expr` returns 1 =
`value`. **Verdict: ok.**

## Problem s5 — nullity of A : R^4 -> R^2 with rank 2 (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own map data, adapted from §II Exercise 2.25 (p. 206). By the rank-nullity
theorem, nullity = n - rank = 4 - 2 (`step2b`) = 2 (`answer2`); no need to find
the null space itself. The gate re-runs `check.expr` `4 - 2`, declared
`value: 2`, tol 1%.

```python
rank_B = 2
n_B = 4
print("domain dim n        =", n_B)
print("rank                =", rank_B)
print("nullity = n - rank  =", n_B - rank_B)
print("s5 check '4 - 2'    =", 4 - 2)
```

output:
```
domain dim n        = 4
rank                = 2
nullity = n - rank  = 2
s5 check '4 - 2'    = 2
```

A map R^4 -> R^2 with rank 2 has nullity 4 - 2 = 2 (rank-nullity theorem).
`check.expr` returns 2 = `value`. **Verdict: ok.**

## Not from Hefferon (our own numbers)

Both worked problems use our own data — s4: A = [[1,2],[2,4]] (rank 1, nullity
1, det 0); s5: a map R^4 -> R^2 of rank 2 (nullity 2). These are not Hefferon's
worked examples. The range-space / rank definition (Definition 2.2), the null
space / nullity definition (Definition 2.11), the rank-nullity theorem (Theorem
2.14), the rank <= dim-domain corollary with equality iff nullity 0 (Corollary
2.17), the one-to-one / nullity-0 / full-rank equivalences (Theorem 2.20), the
rank = dim column space identification (Theorem 2.4), and the
nonsingular/singular definitions (§III Definition 2.7, Lemma 2.9) are all
Hefferon's, applied to our numbers.
