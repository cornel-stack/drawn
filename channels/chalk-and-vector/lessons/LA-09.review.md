# Fact-check — LA-09

Primary source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Chapter Two
§I Definition of Vector Space**, subsection **I.2 Subspaces and Spanning Sets**
— local extract `sources/text/hefferon-linear-algebra/008-definition-of-vector-space.md`
(book pp. 95-107; the lesson cites pp. 95-115). The scalar-multiple / parallel
condition is cross-checked against §I Linear Geometry
(`sources/text/hefferon-linear-algebra/002-linear-geometry.md`, Cauchy-Schwarz,
line 877). The determinant equivalence (det != 0 <=> independent <=> spans the
plane) is the standard fact carried over from **LA-07** (determinant as signed
area); §I.2 does not state it directly, so `step1b` is marked as that standard
equivalent, not a §I.2 quote. The lesson explains the material in its own words;
both worked problems use our own vectors.

## The central claims

**The span of a set is the set of all its linear combinations (`spanEq`, `defEq`).**

> "The span (or linear closure) of a nonempty subset S of a vector space is the
> set of all linear combinations of vectors from S. [S] = {c1 s1 + ... + cn sn |
> c1,...,cn in R and s1,...,sn in S}." — §I.2, Definition 2.13, p. 101, lines
> 1420-1422

For {v,w} this is {a v + b w}, our `spanEq`; the general-k form is `defEq`
verbatim. Remark 2.14 (p. 101, lines 1426-1429) ties it to the Chapter One
"generated" set. **ok.**

**Testing membership in a span is solving a linear system (`sysEq`).**

> "we must show that any member of R2 is a linear combination of these two
> vectors. So we ask: for which vectors with real components x and y are there
> scalars c1 and c2 such that this holds? c1(1,1) + c2(1,-1) = (x,y)" — §I.2,
> Example 2.17, p. 101, lines 1472-1491; solved by "Gauss's Method" + back
> substitution, lines 1492-1501

Example 2.18 (p. 102) and Exercises 2.22-2.23 ("Is the vector in the span of the
set?", p. 103-104) are the same test. Our `sysEq` a v + b w = t is this system
with the target on the right. **ok.**

**Two vectors in R2 span R2 iff independent; dependent (one a multiple of the
other) span only a line through the origin.**

> "for any vector v in R3 the line through the origin containing that vector
> {k v | k in R} is a subspace of R3." — §I.2, Example 2.16, p. 101, lines
> 1456-1459

> "with equality if and only if one vector is a scalar multiple of the other."
> — §I Linear Geometry, Cauchy-Schwarz, line 877 (the scalar-multiple = parallel
> = dependent condition)

A single direction (or a dependent pair, where w = 2v adds nothing) spans a line;
an independent pair spans the whole plane (Example 2.17). The subspace hierarchy
picture Example 2.19 (p. 102-103, lines 1532-1539) shows lines strictly below the
whole space. The det != 0 <=> independent <=> spans the plane link is the standard
equivalent from LA-07 (determinant as area). **ok.**

**The span always contains the zero vector (narration "set every weight to zero
and you get the zero vector, so the origin lies in every span").**

> "closure of S under linear combinations of pairs of vectors gives that
> 0 s + 0 s = 0 is an element of S" — §I.2, Lemma 2.9 proof, p. 98-99, lines
> 1268-1270

> Lemma 1.16(1): "0 . v = 0" — §I.1, p. 92, lines 776-782

The span is a subspace (Lemma 2.15, p. 100, lines 1435-1436) and every subspace
contains 0 (Exercise 2.38c, p. 105-106, lines 2098-2099: "any subspace of R3
must pass through the origin"). **ok.**

## Problem s4 — is t=(4,3) in span{v=(1,1), w=(2,1)}? (`given`, `step1`-`step3`, `answer`, check)

Our own vectors (adapted from Example 2.17's membership test and Exercise 2.24's
reachability problem). Columns are v, w = the s2 transform matrix [[1,2],[1,1]]
(det -1 != 0, independent). The gate re-runs `check.expr` `2*1 + 1*2`, declared
`value: 4` (x-component of 2v + 1w), tol 1%.

```python
import numpy as np
M = np.array([[1,2],[1,1]], float)   # columns v=(1,1), w=(2,1)
t = np.array([4,3], float)
print("solve([[1,2],[1,1]],[4,3]) =", np.linalg.solve(M, t))
print("2*[1,1] + 1*[2,1] =", (2*np.array([1,1]) + 1*np.array([2,1])).tolist())
print("s4 check 2*1 + 1*2 =", 2*1 + 1*2)
```

output:
```
solve([[1,2],[1,1]],[4,3]) = [2. 1.]
2*[1,1] + 1*[2,1] = [4, 3]
s4 check 2*1 + 1*2 = 4
```

Component match gives a + 2b = 4, a + b = 3 (`step1`); elimination gives b = 1
(`step2`); back-substitution a = 3 - b = 2 (`step3`). So t = 2v + 1w (`answer`),
in the span. `check.expr` returns 4 = `value`. **Verdict: ok.**

## Problem s5 — what does span{v=(1,2), w=(2,4)} equal? (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own vectors with w = 2v (dependent). The gate re-runs `check.expr`
`1*4 - 2*2`, declared `value: 0` (the determinant), tol 1%.

```python
import numpy as np
A = np.array([[1,2],[2,4]], float)   # columns v=(1,2), w=(2,4)
print("det[[1,2],[2,4]] =", np.linalg.det(A))
print("s5 check 1*4 - 2*2 =", 1*4 - 2*2)
print("w == 2v ?", np.array_equal(np.array([2,4]), 2*np.array([1,2])))
print("(3,5) on y=2x? 2*3 =", 2*3, "!= 5 ->", 2*3 == 5)
```

output:
```
det[[1,2],[2,4]] = 0.0
s5 check 1*4 - 2*2 = 0
w == 2v ? True
(3,5) on y=2x? 2*3 = 6 != 5 -> False
```

det = 1(4) - 2(2) = 0 (`step1b`), so the pair is dependent: w = 2v (`step2b`).
Hence span{v,w} = the line through v (`answer2`), not the plane. The off-line
target (3,5) is unreachable (2*3 = 6 != 5). `check.expr` returns 0 = `value`.
**Verdict: ok.**

## Not from Hefferon (our own numbers)

Both problems use our own vectors — s4: v=(1,1), w=(2,1), t=(4,3) (independent
pair, a reachable target); s5: v=(1,2), w=(2,4)=2v (dependent pair, a line).
These are not Hefferon's worked vectors (Example 2.17 uses (1,1),(1,-1); the
superhero Exercise 2.24 uses (3,1),(1,2)). The span definition, the
membership-as-linear-system method, the scalar-multiple/parallel condition and
the line-through-origin result are all Hefferon's, applied to our numbers; the
determinant equivalence is carried over from LA-07.
