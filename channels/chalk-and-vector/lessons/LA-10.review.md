# Fact-check — LA-10

Primary source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Chapter Two
§II Linear Independence**, subsection **II.1 Definition and Examples** — local
extract `sources/text/hefferon-linear-algebra/009-linear-independence.md` (book
pp. 108-120; the lesson cites pp. 109-125). The determinant equivalence
(independent <=> det != 0) is stated by Hefferon for the 2x2 and 3x3 cases as
Exercise 1.43(a)-(b) (p. 120); the general n-vector-in-R^n statement is the
standard equivalent carried over from **LA-07** (determinant as signed volume).
The lesson explains the material in its own words; both worked problems use our
own vectors.

## The central claims

**Linear independence: the only combination giving 0 is the trivial one
(`defEq`).**

> "A subset S of a vector space is linearly independent if and only if among its
> elements the only linear relationship c1 s1 + ... + cn sn = 0 is the trivial
> one, c1 = 0, ..., cn = 0 (where si != sj when i != j)." — §II.1, Lemma 1.5,
> p. 110, lines 93-95

Our `defEq` is this verbatim (indices renamed). **ok.**

**Dependent <=> one vector is a combination of the others <=> a non-trivial
combination gives 0 (`depEq`, `depEq2`).**

> "a set of vectors is linearly independent if none of its elements is a linear
> combination of the others from the set. Otherwise the set is linearly
> dependent." — §II.1, Definition 1.4, p. 109, lines 72-74

> "If S is not linearly independent then some si is a linear combination si =
> c1 s1 + ... + cn sn of other vectors from S. Subtracting si from both sides
> gives a relationship involving a nonzero coefficient, the -1 in front of si."
> — §II.1, Lemma 1.5 proof, p. 110, lines 99-102

> "A subset S = {s1, ..., sn} of a vector space is linearly dependent if and
> only if some si is a linear combination of the vectors s1, ..., si-1 listed
> before it." — §II.1, Corollary 1.19, p. 115, lines 846-848

A repeat: "v is a 'repeat' of the vectors in a set S if v in [S] ... v = c1 s1 +
... + cn sn." (Example 1.1 lead-in, p. 108-109, lines 47-48). For `depEq`,
u=(4,3) = v + w = (1,2)+(3,1). **ok.**

**Adding a dependent vector does not change the span.**

> "For v in S, omitting that vector does not shrink the span [S] = [S - {v}] if
> and only if it is dependent on other vectors in the set v in [S]." — §II.1,
> Corollary 1.3, p. 109, lines 67-68

> "Where V is a vector space, S is a subset of that space, and v is an element
> of that space, [S union {v}] = [S] if and only if v in [S]." — §II.1,
> Lemma 1.2, p. 109, lines 49-50

And "a spanning set is minimal if and only if it is linearly independent"
(Corollary 1.14 + remark, p. 113, line 296). **ok.**

**A set containing the zero vector is dependent.**

> "In any vector space, any subset containing the zero vector is linearly
> dependent. ... It is linearly dependent because 0 . v1 + 0 . v2 + 1 . 0 = 0 is
> a nontrivial relationship, since not all of the coefficients are zero." —
> §II.1, Example 1.12, p. 111, lines 216-219

The lesson's narration ("weight the zero vector by anything and the rest by
nothing and still reach zero") is exactly this. A single non-zero vector is
independent: Exercise 1.30(a) ("When is a one-element set linearly
independent?", p. 118, lines 1049-1050) with the standard answer (iff non-zero).
**ok.**

**In R^n any set of more than n vectors is dependent (the ceiling in the plane).**

> "Show that any set of four vectors in R2 is linearly dependent." — §II.1,
> Exercise 1.36(a), p. 119, line 1124

> "What is the most number of elements that a linearly independent subset of R2
> can have?" — §II.1, Exercise 1.36(c), p. 119, lines 1126-1127

The maximal independent set spans the whole space: "a linearly independent set
is maximal if and only if it spans the entire space" (§II.1, p. 117, lines
881-883). Two independent vectors span R2, so any third is dependent — the
lesson's "you can never have three independent vectors in two dimensions."
**ok.**

**The determinant test: independent <=> det != 0 (`detEq`).**

> "Show that this subset of R2 {(a,c),(b,d)} is linearly independent if and only
> if ad - bc != 0." — §II.1, Exercise 1.43(a), p. 120, lines 1171-1181

> "Show that this subset of R3 {(a,d,g),(b,e,h),(c,f,i)} is linearly independent
> iff aei + bfg + cdh - hfa - idb - gec != 0." — §II.1, Exercise 1.43(b),
> p. 120, lines 1182-1205

ad - bc is the 2x2 determinant; the 3x3 expression is the 3x3 determinant. The
general n-vector-in-R^n statement is the standard equivalent from LA-07
(determinant as signed volume: n columns collapse the space iff det = 0).
**ok (Exercise 1.43 for 2x2/3x3; general case the LA-07 standard equivalent).**

## Problem s4 — are v=(1,2), w=(3,1) independent? (`given`, `step1`, `step2`, `answer`, check)

Our own vectors (an independent pair). The gate re-runs `check.expr`
`1*1 - 3*2`, declared `value: -5` (the determinant), tol 1%.

```python
import numpy as np
M = np.array([[1,3],[2,1]], float)   # columns v=(1,2), w=(3,1)
print("det[[1,3],[2,1]] =", np.linalg.det(M))
print("s4 check 1*1 - 3*2 =", 1*1 - 3*2)
```

output:
```
det[[1,3],[2,1]] = -5.000000000000001
s4 check 1*1 - 3*2 = -5
```

det = 1(1) - 3(2) = -5 (`step1`, `step2`), non-zero, so the pair is independent
(`answer`). `check.expr` returns -5 = `value`. **Verdict: ok.**

## Problem s5 — write u=(5,5) as a combination of v=(1,2), w=(3,1) (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own vectors; three in R2, so dependent. The gate re-runs `check.expr`
`2*1 + 1*3`, declared `value: 5` (x-component of 2v + w), tol 1%.

```python
import numpy as np
A = np.array([[1,3],[2,1]], float)   # columns v, w; rows = components
b = np.array([5,5], float)
print("solve([[1,3],[2,1]],[5,5]) =", np.linalg.solve(A, b))
print("2*[1,2] + 1*[3,1] =", (2*np.array([1,2]) + 1*np.array([3,1])).tolist())
print("s5 check 2*1 + 1*3 =", 2*1 + 1*3)
```

output:
```
solve([[1,3],[2,1]],[5,5]) = [2. 1.]
2*[1,2] + 1*[3,1] = [5, 5]
s5 check 2*1 + 1*3 = 5
```

Component match gives a + 3b = 5, 2a + b = 5 (`step1b`); solving gives b = 1,
a = 2 (`step2b`). So u = 2v + w (`answer2`), confirming u is the redundant
vector. `check.expr` returns 5 = `value`. **Verdict: ok.**

## Not from Hefferon (our own numbers)

Both problems use our own vectors — s4: v=(1,2), w=(3,1) (independent pair);
s5: v=(1,2), w=(3,1), u=(5,5)=2v+w (u redundant). These are not Hefferon's
worked vectors. The independence definition (Definition 1.4 / Lemma 1.5), the
dependence-as-redundancy equivalence (Corollary 1.3, 1.19), the
span-unchanged-by-dependent-vector result (Lemma 1.2, Corollary 1.3), the
zero-vector-forces-dependence fact (Example 1.12), and the R^n ceiling
(Exercise 1.36) are all Hefferon's, applied to our numbers; the 2x2/3x3
determinant criterion is Exercise 1.43 and the general determinant equivalence
is carried over from LA-07.
