# Fact-check — LA-20

Source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0). Evidence drawn from the
*Topic: Stable Populations* and *Topic: Method of Powers* topics, which use the
eigenvalue/eigenvector machinery directly. Line numbers refer to the extracted
files in `sources/text/hefferon-linear-algebra/`.

Note on wording: Hefferon writes the acting matrix as `T` and uses the form
`λI − T` (equivalently `(λI − T)⃗v = ⃗0`). The lesson writes the matrix as `A`
and the algebraically identical standard form `(A − λI)⃗v = 0`; these differ
only by an overall sign of the bracket, which does not change the solution set
or the determinant condition. The determinant/characteristic-equation step is
stated verbatim in the source ("characteristic equation").

## Equation `eigEq`

`A v = λ v` — the eigenvector/eigenvalue definition. The source states the
same relation (its matrix is `T`):

> "This leads to ... We consider λ⃗v = T⃗v and solve for λ."
> — *Topic: Stable Populations*, p.401 (`039-topic-stable-populations.md`, l.83)

Also: "we are ... looking for eigenvectors for T that are associated with the
eigenvalue λ = 1. The equation ⃗vn+1 = T⃗vn becomes ⃗v = T⃗v."
(`039-...`, l.32). Verdict: ok.

## Equation `defEq`

`A v = λ v, v ≠ 0` — same identity as `eigEq` with the non-triviality
restriction made explicit. The source requires a non-zero (eigen)vector: the
stable-state computation discards the trivial solution ("This matrix is
nonsingular and so the only solution is p = 0, r = 0", l.79, i.e. no eigenvector
there) and keeps the non-zero eigenspace.

> "We are therefore looking for eigenvectors for T that are associated with the
> eigenvalue λ = 1. ... ⃗v = T⃗v"
> — *Topic: Stable Populations*, p.399 (`039-...`, l.32–33)

Standard identity, consistent with source. Verdict: ok.

## Equation `rearrEq`

`A v − λ v = 0` — a one-step algebraic rearrangement of `A v = λ v`. The source
writes the collected-to-one-side form directly:

> "The equation ⃗0 = (λI−T)⃗v = (I −T)⃗v is"
> — *Topic: Stable Populations*, p.399 (`039-...`, l.33–34)

Standard identity, consistent with source (expanding `(λI − T)⃗v` gives
`λ⃗v − T⃗v`, the negative of the lesson's `A v − λ v`; same equation).
Verdict: ok.

## Equation `factorEq`

`(A − λI) v = 0` — factoring the vector out, with `λ` written as `λI` to keep
dimensions right. This is exactly the source's collected form (sign of the
bracket aside):

> "The equation ⃗0 = (λI−T)⃗v = (I −T)⃗v"
> — *Topic: Stable Populations*, p.399 (`039-...`, l.33–34)

Verdict: ok.

## Equation `charEq`

`det(A − λI) = 0` — the characteristic equation; eigenvalues are the λ making
the matrix singular. The source forms exactly this determinant from
`(λI − T)` and names it:

> "= (λ −.9)(λ −.99) −(.10)(.01) = λ2 −1.89λ + .89 ... We already know that
> λ = 1 is one solution of this characteristic equation."
> — *Topic: Stable Populations*, p.401 (`039-...`, l.90–91)

The phrase "characteristic equation" also appears in
`038-topic-method-of-powers.md` (l.129, l.147) and "characteristic polynomial"
(l.6–7). The "singular ⟺ det = 0" reading is reflected in the source's own
reasoning at l.79 ("This matrix is nonsingular and so the only solution is
p = 0, r = 0"). Verdict: ok.

## Equation `given`

`A = [[2,1],[1,2]], v = [1,1]` — a worked verification example with numbers
changed from the source (per house rules). `A` is real symmetric with distinct
eigenvalues; numpy confirms the eigenpair below. Method follows `λ⃗v = T⃗v`
(p.401). Verdict: ok.

## Equation `step1`

`A v = [2(1)+1(1); 1(1)+2(1)]` — the matrix–vector product. Recomputed below
(Problem s4): `A@[1,1] = [3,3]`. Verdict: ok.

## Equation `step2`

`= [3;3] = 3[1;1]` — output is a scalar multiple of the input. numpy:
`A@[1,1] = [3 3]`, and `3*[1,1] = [3 3]`. Verdict: ok.

## Equation `answer`

`λ = 3` — the eigenvalue. numpy `eig(A)` returns {1, 3}; 3 is the eigenvalue
for v=[1,1]. Verdict: ok.

## Equation `given2`

## Problem `s4`

```python
import numpy as np
A = np.array([[2, 1], [1, 2]])
v = np.array([1, 1])
print("A@v   =", A @ v)         # expect [3 3]
print("3*v   =", 3 * v)         # expect [3 3]
print("lambda =", (2*1 + 1*1) / 1)   # check expr
print("eig(A) =", sorted(np.linalg.eig(A)[0].real))
```

output:
```
A@v   = [3 3]
3*v   = [3 3]
lambda = 3.0
eig(A) = [1.0, 3.0]
```

`A@v = [3,3] = 3·v`, so v=[1,1] is an eigenvector with λ=3. The `check:` expr
`(2*1 + 1*1)/1 = 3.0` matches the boxed `value: 3`. Verdict: ok.

## Problem `s5`

```python
import numpy as np
A = np.array([[2, 1], [1, 2]])
v = np.array([1, -1])
print("A@v   =", A @ v)         # expect [1 -1]
print("1*v   =", 1 * v)         # expect [1 -1]
print("lambda =", (2*1 + 1*(-1)) / 1)   # check expr
print("eig(A) =", sorted(np.linalg.eig(A)[0].real))
```

output:
```
A@v   = [ 1 -1]
1*v   = [ 1 -1]
lambda = 1.0
eig(A) = [1.0, 3.0]
```

`A@v = [1,−1] = 1·v`, so v=[1,−1] is an eigenvector with λ=1 of the *same*
matrix A. The `check:` expr `(2*1 + 1*(-1))/1 = 1.0` matches the boxed
`value: 1`. Verdict: ok.
