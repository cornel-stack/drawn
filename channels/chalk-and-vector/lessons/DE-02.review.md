## Equation `genForm` — `y' = f(x, y)`

The general first-order form that a slope field visualises, and the tangent-line
reading that underpins it:

> "In particular, we consider a first-order differential equation of the form"
> — §4.2, "Creating Direction Fields", p. 317 (display equation dropped)

> "The idea behind a direction field is the fact that the derivative of a
> function evaluated at a given point is the slope of the tangent line to the
> graph of that function at the same point." — §4.2, p. 318

> "A direction field (slope field) is a mathematical object used to graphically
> represent solutions to a first-order differential equation. At each point in a
> direction field, a line segment appears whose slope is equal to the slope of a
> solution to the differential equation passing through that point." — §4.2,
> Definition, p. 320

Writing the rule as `y' = f(x, y)` is exactly this form. **Verdict: ok.**

## Equation `fieldEq` — `y' = x - y`

> the point … then the slope of the solution at that point must equal … To start

## Symbolic and numeric verification (sympy / numpy)

```python
import sympy as sp
import numpy as np

x = sp.symbols('x')

# 1) y = x - 1 + 2 e^{-x} satisfies y' = x - y, y(0)=1, and y -> x-1 as x->inf
y = x - 1 + 2*sp.exp(-x)
print("1a) y' - (x - y) residual:", sp.simplify(sp.diff(y, x) - (x - y)))
print("1b) y(0):", y.subs(x, 0))
print("1c) limit y - (x-1) as x->inf:", sp.limit(y - (x-1), x, sp.oo))
f = sp.Function('f')
sol = sp.dsolve(sp.Eq(f(x).diff(x), x - f(x)), f(x), ics={f(0): 1})
print("1d) dsolve y'=x-y, y(0)=1:", sol)

# 2) Euler two-step, y'=x-y, y(0)=1, h=0.5
feuler = lambda xn, yn: xn - yn
h, x0, y0 = 0.5, 0.0, 1.0
y1 = y0 + h*feuler(x0, y0); x1 = x0 + h
y2 = y1 + h*feuler(x1, y1); x2 = x1 + h
print("2a) y1:", y1, "at x1:", x1)
print("2b) y2:", y2, "at x2:", x2, "(estimate y(1))")
print("2c) exact y(1) = 2 e^{-1}:", 2*np.exp(-1))
print("2d) check expr 2*np.exp(-1):", 2 * np.exp(-1), "declared 0.735759")

# 3) autonomous y' = y(3 - y): equilibria and stability
y_s = sp.symbols('y')
g = y_s*(3 - y_s)
eqs = sp.solve(sp.Eq(g, 0), y_s)
print("3a) equilibria of y(3-y):", eqs)
gp = sp.diff(g, y_s)
for e in eqs:
    slope = gp.subs(y_s, e)
    print(f"3b) g'({e}) = {slope} -> {'stable' if slope<0 else 'unstable'}")
```

output:
```
1a) y' - (x - y) residual: 0
1b) y(0): 1
1c) limit y - (x-1) as x->inf: 0
1d) dsolve y'=x-y, y(0)=1: Eq(f(x), x - 1 + 2*exp(-x))
2a) y1: 0.5 at x1: 0.5
2b) y2: 0.5 at x2: 1.0 (estimate y(1))
2c) exact y(1) = 2 e^{-1}: 0.7357588823428847
2d) check expr 2*np.exp(-1): 0.7357588823428847 declared 0.735759
3a) equilibria of y(3-y): [0, 3]
3b) g'(0) = 3 -> unstable
3b) g'(3) = -3 -> stable
```

So `y = x - 1 + 2e^{-x}` satisfies `y'=x-y` identically, meets `y(0)=1`, and has
`y → x-1` as `x→∞` (asymptote confirmed); the Euler two-step gives `y1=0.5`,
`y2=0.5` (estimate `y(1)≈0.5`) against the exact `y(1)=2e^{-1}=0.735759`
(undershoot confirmed); and `y'=y(3-y)` has equilibria `y=0` (unstable) and
`y=3` (stable). **All confirmed.**
