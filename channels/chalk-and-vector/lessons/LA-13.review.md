# Fact-check — LA-13

Primary source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Chapter Three
§IV Matrix Operations — IV.4 Inverses** (local extract
`sources/text/hefferon-linear-algebra/018-matrix-operations.md`, book pp.
254-259) for the definition of the inverse matrix, the two-sided property, the
invertible <=> nonsingular theorem, the 2x2 inverse formula, and solving linear
systems with the inverse. Secondary source: **Chapter Three §III Computing
Linear Maps** (`017-computing-linear-maps.md`, book pp. 226-227) for the
nonsingular <=> full-rank <=> isomorphism equivalences, which with the
rank-nullity machinery recorded in LA-12 give the five-way chain the lesson
states. Both worked problems use our own 2x2 matrices (numbers changed),
adapted from §IV Exercises 4.13/4.14 (Problem A) and §III Example 2.11 / §IV
Exercise 4.13(c) (Problem B).

## The central claims

**The inverse is defined by A A^-1 = A^-1 A = I (`invEq`, `invEq2`).**

> "A matrix G is a left inverse matrix of the matrix H if GH is the identity
> matrix. It is a right inverse if HG is the identity. A matrix H with a
> two-sided inverse is an invertible matrix. That two-sided inverse is denoted
> H^{-1}." — §IV, Definition 4.1, p. 255, lines 3149-3152

> "Some functions have a two-sided inverse, another function that is the inverse
> both from the left and from the right. ... if a function f has a two-sided
> inverse then it is unique, so we call it 'the' inverse and write f^{-1}."
> — §IV, p. 255, lines 3139-3144

So the inverse A^{-1} satisfies both A A^{-1} = I and A^{-1} A = I. **ok.**

**The 2x2 inverse formula A^-1 = (1/det A)[[d,-b],[-c,a]] (`formulaEq`).**

> "With this procedure we can give a formula for the inverse of a general 2x2
> matrix, which is worth memorizing. 4.11 Corollary The inverse for a 2x2 matrix
> exists and equals [[a,b],[c,d]]^{-1} = (1/(ad - bc)) [[d,-b],[-c,a]] if and
> only if ad - bc =/= 0." — §IV, Corollary 4.11, p. 259, lines 3570-3588

The denominator `ad - bc` is exactly `det A` for a 2x2 matrix, so
`1/(ad-bc) = 1/det A`, and the cofactor matrix `[[d,-b],[-c,a]]` matches the
lesson verbatim. **ok.**

**Invertible <=> det != 0; det = 0 => singular => no inverse (`singEq`,
`step2b`, `answer2`).**

> "The inverse for a 2x2 matrix exists and equals ... if and only if
> ad - bc =/= 0." — §IV, Corollary 4.11, p. 259, line 3588

> "A matrix is invertible if and only if it is nonsingular." — §IV, Theorem 4.3,
> p. 256, line 3160

When `ad - bc = det A = 0` the formula divides by zero and no inverse exists;
such a matrix is singular, hence not invertible. **ok.**

**The five-way chain: invertible <=> det != 0 <=> independent columns <=> full
rank <=> nullity 0.**

> "A square matrix represents nonsingular maps if and only if it is a nonsingular
> matrix. ... H is nonsingular if and only if its row rank is n, which is true if
> and only if H's rank is n by Theorem Two.III.3.11, which is true if and only if
> h's rank is n by Theorem 2.4, which is true if and only if h is an isomorphism
> by Theorem I.2.3." — §III, Lemma 2.9, p. 227, lines 2105-2117

Hefferon states invertible <=> nonsingular (Theorem 4.3) and nonsingular <=>
full rank (rank n) <=> isomorphism (Lemma 2.9). Full rank for a square matrix
means the n columns are linearly independent (dim column space = n), and by the
one-to-one <=> nullity-0 <=> rank-n equivalences established in **LA-12**
(Theorem Two.II.2.20 / Corollary 2.17) this is equivalent to nullity 0. The
determinant link (det != 0 <=> nonsingular) is the standard determinant
characterisation of this chapter. So all five conditions coincide. **ok.**

**The inverse solves a system: A x = b => x = A^-1 b (`invEq2` narration / s3).**

> "If we had a left inverse map g then we could apply it to both sides
> g o h(x) = g(d) to get x = g(d). Restating in terms of the matrices, we want to
> multiply by the inverse matrix RepC,B(g) · RepC(d) to get RepB(x)." — §IV,
> p. 256, lines 3212-3215

So from A x = b one gets x = A^{-1} b. **ok.**

## Problem s4 — inverse of A = [[2,1],[1,1]] (`given`, `step1`, `step2`, `answer`, check)

Our own matrix, adapted from §IV Exercise 4.13(a)/4.14 (p. 259). det =
2*1 - 1*1 = 1 != 0 (`step1`), so the inverse exists; the formula gives
A^{-1} = (1/1)[[1,-1],[-1,2]] (`step2`) = [[1,-1],[-1,2]] (`answer`); checked by
A A^{-1} = I. The gate re-runs `check.expr` `2*1 - 1*1`, declared `value: 1`,
tol 1%.

```python
import numpy as np
A = np.array([[2,1],[1,1]], float)
detA = 2*1 - 1*1
print("det A = 2*1 - 1*1   =", detA)
Ainv_formula = (1/detA)*np.array([[1,-1],[-1,2]], float)
print("A^-1 (formula)      =\n", Ainv_formula)
Ainv_np = np.linalg.inv(A)
print("np.linalg.inv(A)    =\n", Ainv_np)
print("A @ A^-1            =\n", A @ Ainv_np)
print("A @ A^-1 == I?      =", np.allclose(A @ Ainv_np, np.eye(2)))
print("formula == numpy?   =", np.allclose(Ainv_formula, Ainv_np))
print("s4 check '2*1 - 1*1'=", 2*1 - 1*1)
```

output:

## Problem s5 — B = [[1,2],[2,4]] is singular (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own matrix, adapted from §III Example 2.11 (p. 227) and §IV Exercise 4.13(c)
(p. 259). det = 1*4 - 2*2 = 0 (`step1b`), so B is singular (`step2b`) and has no
inverse (`answer2`); row2 = 2*row1 collapses the plane onto a line. The gate
re-runs `check.expr` `1*4 - 2*2`, declared `value: 0`, tol 1%.

```python
import numpy as np
B = np.array([[1,2],[2,4]], float)
detB = 1*4 - 2*2
print("det B = 1*4 - 2*2   =", detB)
print("np.linalg.det(B)    =", round(np.linalg.det(B), 12))
print("row2 == 2*row1?     =", np.allclose(B[1], 2*B[0]))
try:
    np.linalg.inv(B)
    print("inv(B)              = computed (unexpected)")
except np.linalg.LinAlgError as e:
    print("np.linalg.inv(B)    = LinAlgError:", e)
print("s5 check '1*4 - 2*2'=", 1*4 - 2*2)
```

output:
```
det B = 1*4 - 2*2   = 0
np.linalg.det(B)    = 0.0
row2 == 2*row1?     = True
np.linalg.inv(B)    = LinAlgError: Singular matrix
s5 check '1*4 - 2*2'= 0
```

det 0 (singular), row2 = 2*row1, and `np.linalg.inv` raises `LinAlgError:
Singular matrix` — no inverse. `check.expr` returns 0 = `value`. **Verdict: ok.**

## Not from Hefferon (our own numbers)

Both worked problems use our own data — s4: A = [[2,1],[1,1]] (det 1, inverse
[[1,-1],[-1,2]]); s5: B = [[1,2],[2,4]] (det 0, singular, no inverse). These are
not Hefferon's worked examples (adapted from §IV Exercises 4.13/4.14 and §III
Example 2.11). The inverse definition (Definition 4.1), the two-sided-inverse
property, the invertible <=> nonsingular theorem (Theorem 4.3), the 2x2 inverse
formula with its det != 0 condition (Corollary 4.11), the nonsingular <=>
full-rank <=> isomorphism chain (§III Lemma 2.9), and solving systems by
x = A^{-1} b (§IV p. 256) are all Hefferon's, applied to our numbers.
