# Fact-check — LA-26

All equations are standard, correct linear algebra. The cited section
(Hefferon §Five.I Complex Vector Spaces) provides the complex-number
foundation (`x^2+1=(x-i)(x+i)`, `i^2=-1`, `|a+bi|=\sqrt{a^2+b^2}`, the
quadratic formula and factoring over C). The rotation-matrix form appears
verbatim in Hefferon's *Topic: Orthonormal Matrices* (p.302). The complex
eigenvalues of a rotation and their geometric meaning are a standard result
consistent with §Five.I; each is verified mathematically below.

## Equation `eigEq`

`\lambda = \cos\theta \pm i\sin\theta = e^{\pm i\theta}`

Standard result. For the rotation matrix (rotEq) the characteristic equation
is `\lambda^2 - 2\cos\theta\,\lambda + 1 = 0` (trace `2\cos\theta`, det `1`).
Quadratic formula:

```
λ = cosθ ± √(cos²θ − 1) = cosθ ± √(−sin²θ) = cosθ ± i·sinθ
```

By Euler's formula (consistent with §Five.I complex plane) `\cos\theta + i\sin\theta = e^{i\theta}`,
so the roots are `e^{\pm i\theta}`, on the unit circle since `|\lambda|^2 = \cos^2\theta + \sin^2\theta = 1`.
Source anchor — §Five.I: "if we imagine a root — traditionally denoted i, so
that i^2 + 1 = 0 — then x^2 + 1 factors into a product of linears (x−i)(x+i)."

## Equation `rotEq`

> "RepE2,E2(t) = [[a, −b],[b, a]] … Let θ be the counter-clockwise angle …
> The first matrix above represents, with respect to the standard bases, a
> rotation of the plane by θ radians."
> — Hefferon, *Topic: Orthonormal Matrices*, p.302

With `a = \cos\theta`, `b = \sin\theta` this is exactly
`R = [[\cos\theta, -\sin\theta],[\sin\theta, \cos\theta]]`. OK.

## Equation `charEq`

`\lambda^2 - 2\cos\theta\,\lambda + 1 = 0`. For a 2×2 matrix the
characteristic polynomial is `\lambda^2 - (\mathrm{tr})\lambda + \det`.
For rotEq: `\mathrm{tr} = \cos\theta + \cos\theta = 2\cos\theta` and
`\det = \cos\theta\cdot\cos\theta - (-\sin\theta)(\sin\theta) = \cos^2\theta + \sin^2\theta = 1`.
Hence `\lambda^2 - 2\cos\theta\,\lambda + 1 = 0`. Verified mathematically.

## Equation `rootsEq`

`\lambda = \cos\theta \pm i\sin\theta`. Quadratic formula on charEq:

```
λ = [2cosθ ± √(4cos²θ − 4)]/2 = cosθ ± √(cos²θ − 1)
  = cosθ ± √(−sin²θ) = cosθ ± i·sinθ
```

A complex-conjugate pair on the unit circle. Consistent with §Five.I:
"the roots of ax^2+bx+c are … (if the discriminant b^2−4ac is negative then
the polynomial has no real number roots)"; discriminant here is
`4\cos^2\theta - 4 = -4\sin^2\theta < 0`. Verified mathematically.

## Equation `polarEq`

`\lambda = r\,e^{i\theta}`: rotate by θ, scale by r. Standard polar form of a
complex number. §Five.I plots `a+bi` on the plane with "the distance of the
point from the origin is |a + bi| = √(a^2 + b^2)" — that distance is `r`, and
multiplying a vector in the invariant plane by `r e^{i\theta}` rotates it by
`\theta` and scales its length by `r`. Verified mathematically.

## Equation `detEq`

`|\lambda|^2 = \det`. For a real 2×2 matrix with complex-conjugate eigenvalues
`\lambda, \bar\lambda`, the determinant equals the product of eigenvalues:
`\det = \lambda\bar\lambda = |\lambda|^2`. Consistent with §Five.I
`|a+bi| = \sqrt{a^2+b^2}` (so `|a+bi|^2 = a^2+b^2 = (a+bi)(a-bi)`). Verified
mathematically and numerically (see Problem `s5`).

## Equation `given`

`R = [[0,-1],[1,0]]` is rotEq evaluated at `\theta = 90°`
(`\cos 90° = 0`, `\sin 90° = 1`). Matches Hefferon's `[[a,-b],[b,a]]` form
with `a=0, b=1`. OK.

## Problem `s4`

```python
import numpy as np
R = [[0, -1], [1, 0]]          # R(90°)
print("eigvals:", np.linalg.eigvals(R))
print("det:", np.linalg.det(R))
print("check np.sqrt(0*0 - (-1)*1):", np.sqrt(0*0 - (-1)*1))
```

output:
```
eigvals: [0.+1.j 0.-1.j]
det: 1.0
check np.sqrt(0*0 - (-1)*1): 1.0
```

Eigenvalues are `±i` (boxed answer), det = 1 so `|\lambda| = \sqrt{1} = 1`
(pure rotation). The `check.expr` `np.sqrt(0*0 - (-1)*1)` = `1.0` matches the
boxed `value: 1`.

## Problem `s5`

```python
import numpy as np
print("check np.sqrt(0.64):", np.sqrt(0.64))

# verify |lambda|^2 = det for a complex-conjugate pair with det = 0.64
b = np.sqrt(0.64 - 0.25)
M = np.array([[0.5, -b], [b, 0.5]])     # rotation-scaling matrix, det 0.64
ev = np.linalg.eigvals(M)
print("eigvals:", ev)
print("det:", np.linalg.det(M))
print("|lambda|^2:", abs(ev[0])**2)
```

output:
```
check np.sqrt(0.64): 0.8
eigvals: [0.5+0.6244998j 0.5-0.6244998j]
det: 0.64
|lambda|^2: 0.6400000000000001
```

`|\lambda| = \sqrt{0.64} = 0.8` (boxed answer), and `|\lambda|^2 = 0.64 = \det`
confirms detEq for a conjugate pair. The `check.expr` `np.sqrt(0.64)` = `0.8`
matches the boxed `value: 0.8`.
