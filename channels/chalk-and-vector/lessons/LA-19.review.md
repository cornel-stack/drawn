# Fact-check — LA-19

All equations are standard linear-algebra identities from Hefferon's
*Linear Algebra* (CC BY-SA 3.0). The two worked problems use the penny data
that appears verbatim in the "Topic: Line of Best Fit" section, and the
projection fraction 7110/12600 appears **literally** in the source.

## Equation `sysEq`

The fit is written as one equation per data point. For the penny (through the
origin) the source writes exactly:

> "30m = 16 / 60m = 34 / 90m = 51" — Hefferon, *Linear Algebra*, Topic: Line of
> Best Fit, p.296.

For the general (intercept + slope) case the source writes the same per-point
form:

> "b + 1870m = 268.8 / b + 1880m = 264.5 / ... / b + 1950m = 241.4" — Topic:
> Line of Best Fit, p.296. The board item `b + m x_i = y_i` is the general case
> of this.

## Equation `matEq`

The linear system is stacked into a matrix times the unknowns equals the data
vector. The source instructs:

> "Write the linear system's matrix of coefficients and also its vector of
> constants, the world record times. A = [...], v = [...]" — Topic: Line of
> Best Fit, p.297.

and Theorem 3.8 defines A as:

> "let A be the matrix whose columns are the β's" — §VI.3 Projection Into a
> Subspace, Thm 3.8, p.290.

Standard restatement `A x = v`; consistent with the source.

## Equation `projEq`

Orthogonal projection onto the column space is the closest reachable point:

> "An orthogonal projection of the data vector into the line subspace gives a
> best guess, the vector in the subspace closest to the data vector." — Topic:
> Line of Best Fit, p.296.

and the subspace theorem:

> "the orthogonal projection is projM(v) = c1 β1 + · · · + ck βk ... That is,
> projM(v) = A(ATA)−1AT · v." — §VI.3, Thm 3.8, p.290. Board item
> `p = proj_col(A) v` is this, naming the column space explicitly.

## Equation `orthoEq`

The residual is orthogonal to the column space, hence A^T times the residual is
zero. From the proof of Theorem 3.8:

> "0 = AT(v − Ac) = ATv − ATAc" — §VI.3, proof of Thm 3.8, p.291.

and Lemma 3.7:

> "For any v ∈ Rⁿ the vector v − projM(v) is perpendicular to every vector in
> M." — §VI.3, Lemma 3.7, p.289.

Board item `A^T(v − A x̂) = 0` is exactly the first equation of the proof.

## Equation `normalEq`

The normal equations A^T A x̂ = A^T v are the rearrangement of the proof line:

> "0 = AT(v − Ac) = ATv − ATAc" — §VI.3, proof of Thm 3.8, p.291.

Moving ATAc to the other side gives ATAc = ATv. Standard identity (the "normal
equations"), consistent with the source's own algebra.

## Equation `solveEq`

The closed-form solution. Stated twice in the source:

> "the coefficients ci are the entries of the vector (ATA)−1AT · v" — §VI.3,
> Thm 3.8, p.290.

> "Those coefficients are the entries of the vector (ATA)−1AT · v." — Topic:
> Line of Best Fit, p.297.

Board item `x̂ = (A^T A)^{-1} A^T v` matches verbatim.

## Equation `step1`

For a one-column model the normal equation reduces to the line-projection
scalar coefficient v·a / a·a. From Definition 1.1:

> "proj[s](v) = (v • s / s • s) · s" — §VI.1 Orthogonal Projection Into a Line,
> Def 1.1, p.275.

The scalar coefficient (v • s)/(s • s) is the slope m here. Standard identity,
consistent with the source (it is the single-column special case of the normal
equations).

## Equation `step2`

The numeric substitution. The source performs exactly this projection on the
penny data and prints the same fraction:

> "[16,34,51] • [30,60,90] / [30,60,90] • [30,60,90] · [30,60,90] = 7110/12600
> · [30,60,90]" — Topic: Line of Best Fit, p.296.

So numerator = 30(16)+60(34)+90(51) = 7110 and denominator = 30²+60²+90² =
12600 are both **literally in the source**. Board item `= 7110/12600` is quoted.

## Equation `given2`

Set-up for the orthogonality check: single-column model a and residual r.
This is a constructed (illustrative) 2-component example, not a verbatim source
line. Standard restatement, consistent with the governing result:

> "the vector v − projM(v) is perpendicular to every vector in M" — §VI.3,
> Lemma 3.7, p.289,

and the single-column penny model a = flips (§Line of Best Fit, p.296).

## Equation `step1b`

The perpendicularity test is the dot product. From the line-projection
derivation:

> "(v − cp s) • s = 0" — §VI.1, p.275.

Board item `a · r = 30(−0.4) + 60(0.2)` is this dot product written out.
Standard identity, consistent with the source.

## Equation `step2b`

Pure arithmetic: 30(−0.4)+60(0.2) = −12 + 12. Not a verbatim source line;
standard restatement of the dot-product arithmetic for the orthogonality
condition of §VI.1 p.275. Recomputed below (= 0).

## Equation `answer2`

Zero dot product ⇒ perpendicular, which is what the normal equations / Lemma
3.7 demand:

> "the vector v − projM(v) is perpendicular to every vector in M" — §VI.3,
> Lemma 3.7, p.289,

with "perpendicular ⇔ dot product zero" from §VI.1 p.275 ("(v − cp s) • s = 0").
Standard identity, consistent with the source.

## Problem `s4`

Least-squares slope through the origin for the penny data (30,16),(60,34),(90,51):

```python
num = 30*16 + 60*34 + 90*51
den = 30**2 + 60**2 + 90**2
m = num / den
print("numerator =", num)      # expect 7110 (quoted in source)
print("denominator =", den)    # expect 12600 (quoted in source)
print("m =", m)
print("rounded 3dp =", round(m, 3))
print("|m - boxed 0.5643| =", abs(m - 0.5643))
```

output:
```

denominator = 12600
m = 0.5642857142857143
rounded 3dp = 0.564
|m - boxed 0.5643| = 1.4285714285744433e-05
```

The fraction 7110/12600 is **literally in the source** (Topic: Line of Best
Fit, p.296: "= 7110/12600 ·"), and the source quotes "m = 7110/12600 ≈ 0.56"
(p.296). The boxed answer m ≈ 0.564 matches (within 1.4e-05 of the check value
0.5643, well inside tol 0.01). The `check:` expr
`(30*16 + 60*34 + 90*51) / (30**2 + 60**2 + 90**2)` = 0.56428… agrees with
value 0.5643.

## Problem `s5`

Residual orthogonal to the single column (a · r = 0):

```python
a = (30, 60)
r = (-0.4, 0.2)
dot = a[0]*r[0] + a[1]*r[1]
print("30*(-0.4) =", 30*(-0.4))
print("60*(0.2) =", 60*0.2)
print("a . r =", dot)
```

output:
```
30*(-0.4) = -12.0
60*(0.2) = 12.0
a . r = 0.0
```

The dot product is exactly 0, so the residual is orthogonal to the column, as
the normal equations / Lemma 3.7 (p.289) require. The `check:` expr
`30*(-0.4) + 60*0.2` = 0.0 agrees with value 0 (within tol 0.01).
