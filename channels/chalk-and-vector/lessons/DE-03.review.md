**Extraction note.** As with §4.1/§4.2, the text extraction dropped every

## Equation `equilib` — `h(y) = 0 ⇒ y = 0`

For `dy/dx = x y`, `h(y)=y`, so `h(y)=0` gives `y=0`. Verified `y=0` solves

## Equation `exInt` — `ln|y| = x^2/2 + C`

## Equation `exExp` — `y = A e^{x^2/2}`

Exponentiating and absorbing the constant:

> "Now exponentiate both sides of the equation … Again define a new constant [A]

> can actually have either sign … Therefore the solution can be written as" —

Exponentiating `ln|y| = x^2/2 + C` gives `y = A e^{x^2/2}` with `A = ±e^C` of

## Problem 1 — `given`, `step1`, `step2`, `answer` (s5)

`dy/dx = 3x^2 y, y(0)=2`. The IVP framing and five-step method are Example 4.11
and the Problem-Solving Strategy (pp. 333-335); numbers are ours.

- `given` `dy/dx = 3x^2 y, y(0)=2` — separable with `g(x)=3x^2`, `h(y)=y`.
- `step1` `∫ dy/y = ∫ 3x^2 dx ⇒ ln|y| = x^3 + C` — integrate both sides.
- `step2` `y = A e^{x^3}, y(0)=A=2` — exponentiate; apply initial condition.
- `answer` `y = 2 e^{x^3}` — boxed; `sympy.dsolve` confirms `Eq(f(x),
  2*exp(x**3))` (below).

**Verdict: ok** (all four).

## Problem 2 — `given2`, `step1b`, `step2b`, `answer2` (s6)

`dy/dx = x/y, y(0)=3`. Same method; the implicit first form is licensed by the
caveat on step 4 ("Quite often we have to be satisfied with finding [y] as an

- `given2` `dy/dx = x/y, y(0)=3` — separable, `g(x)=x`, `h(y)=1/y`.
- `step1b` `∫ y dy = ∫ x dx ⇒ y^2 - x^2 = C` — implicit solution (a hyperbola).
- `step2b` `y(0)=3 ⇒ C=9 ⇒ y = √(x^2+9)` — fix the constant, take the positive

- `answer2` `y(4) = √(16+9) = 5` — boxed; `sympy.dsolve` confirms `Eq(f(x),
  sqrt(x**2+9))` and `y(4)=5` (below).

**Verdict: ok** (all four).

## Symbolic and numeric verification (sympy / numpy)

```python
import sympy as sp
import numpy as np

x = sp.symbols('x')
f = sp.Function('f')

# 1) dy/dx = x*y -> general solution y = A e^{x^2/2}, with y=0 equilibrium
sol = sp.dsolve(sp.Eq(f(x).diff(x), x*f(x)), f(x))
print("1a) dsolve dy/dx = x*y:", sol)
A = sp.symbols('A')
yg = A*sp.exp(x**2/2)
print("1b) residual y'-x*y for y=A e^{x^2/2}:", sp.simplify(sp.diff(yg,x) - x*yg))
print("1c) y=0 residual:", sp.simplify(sp.diff(sp.Integer(0),x) - x*0))

# 2) Problem 1: dy/dx = 3x^2 y, y(0)=2
sol1 = sp.dsolve(sp.Eq(f(x).diff(x), 3*x**2*f(x)), f(x), ics={f(0):2})
print("2a) dsolve dy/dx=3x^2 y, y(0)=2:", sol1)
y1 = 2*sp.exp(x**3)
print("2b) residual y'-3x^2 y for y=2e^{x^3}:", sp.simplify(sp.diff(y1,x) - 3*x**2*y1))
print("2c) y1(0):", y1.subs(x,0))
print("2d) y1(1) exact:", sp.nsimplify(y1.subs(x,1)), "=", float(y1.subs(x,1)))
print("2e) check expr 2*np.exp(1):", 2*np.exp(1), "declared 5.436564")

# 3) Problem 2: dy/dx = x/y, y(0)=3
sol2 = sp.dsolve(sp.Eq(f(x).diff(x), x/f(x)), f(x), ics={f(0):3})
print("3a) dsolve dy/dx=x/y, y(0)=3:", sol2)
y2 = sp.sqrt(x**2+9)
print("3b) residual y'-x/y for y=sqrt(x^2+9):", sp.simplify(sp.diff(y2,x) - x/y2))
print("3c) y2(0):", y2.subs(x,0))
print("3d) y2(4):", y2.subs(x,4))
print("3e) check expr np.sqrt(4**2+9):", np.sqrt(4**2+9), "declared 5.0")
```
