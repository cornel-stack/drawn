# Fact-check — LA-15

Primary source: Jim Hefferon, *Linear Algebra* (CC BY-SA 3.0), **Chapter Four
§III Laplace's Formula** (local extract
`sources/text/hefferon-linear-algebra/028-laplace-s-formula.md`, book
pp. 363-367) for the cofactor (Laplace) expansion, the definition of the minor
and the cofactor with its (−1)^{i+j} sign, expansion along any row or column,
and the sparse-column strategy. Both worked problems use our own 3x3 matrices
(numbers changed): Problem A a symmetric matrix expanded along the first row,
Problem B an upper-triangular matrix expanded down the sparse first column to
illustrate the diagonal-product corollary.

## The central claims

**Cofactor (Laplace) expansion: det A = sum_j a_{ij} C_{ij} along a row (or
column) (`expEq`, `expEq2`).**

> "1.5 Theorem (Laplace Expansion of Determinants) Where T is an n×n matrix, we
> can find the determinant by expanding by cofactors on any row i or column j.
> |T| = ti,1 · Ti,1 + ti,2 · Ti,2 + · · · + ti,n · Ti,n
>      = t1,j · T1,j + t2,j · T2,j + · · · + tn,j · Tn,j" — §III, Theorem 1.5,
> p. 365, lines 347-350

The first line is the expansion along any row i (`expEq2`, with the first row
i = 1 giving `expEq`); the second line is the expansion down any column j. Each
entry is weighted by its cofactor. The 3x3 first-row instance is written out in
full in Example 1.1 (p. 363-364, lines 278-296), ending
`= t1,1·|t2,2 t2,3; t3,2 t3,3| − t1,2·|t2,1 t2,3; t3,1 t3,3| + t1,3·|t2,1 t2,2;
t3,1 t3,2|`. **ok.**

**The minor M_{ij} is the determinant of the submatrix left by deleting row i and
column j; the cofactor C_{ij} = (−1)^{i+j} M_{ij} (`minorEq`).**

> "1.2 Definition For any n×n matrix T, the (n−1)×(n−1) matrix formed by deleting
> row i and column j of T is the i, j minor of T. The i, j cofactor Ti,j of T is
> (−1)i+j times the determinant of the i, j minor of T." — §III, Definition 1.2,
> p. 364, lines 300-302

Confirmed numerically by Hefferon's own Example 1.4 (p. 364, lines 330-343):

> "T1,2 = (−1)1+2 · |4 6; 7 9| = 6   T2,2 = (−1)2+2 · |1 3; 7 9| = −12"

**You may expand along any row or column (`signEq` / `minorEq` narration; the
"choose the lazy row" argument).**

> "we can find the determinant by expanding by cofactors on any row i or column
> j." — §III, Theorem 1.5, p. 365, lines 347-348

> "1.7 Example A row or column with many zeroes suggests a Laplace expansion."
> — §III, Example 1.7, p. 365, line 406

Example 1.6 even computes the same determinant two ways — "by expanding along the
first row" and then "we could expand down the second column" — getting 0 both
times (p. 365, lines 353-405), and Example 1.7 shows the zero entries killing
their terms: `0 · (+1)|..| + 1 · (−1)|..| + 0 · (+1)|..| = 16` (p. 365,
lines 418-436). This is the lesson's "every zero entry kills an entire minor".
**ok.**

**The checkerboard sign pattern (`signEq`).** The sign on the (i,j) cofactor is
(−1)^{i+j} (Definition 1.2, p. 364, lines 300-302), which alternates +,−,+ as i+j
runs even, odd, even — a checkerboard with + in the top-left corner. The explicit
+,−,+ pattern appears in Example 1.6's expansion `1·(+1)|..| + 2·(−1)|..| +
3·(+1)|..|` (p. 365, lines 367-385). **ok.**

**Triangular matrix → determinant is the product of the diagonal (`step2b`,
`answer2`).** Hefferon defines upper-triangular (Exercise 1.26, p. 368, lines
921-922: "each i, j entry is zero ... when i > j") but does not box the
det-equals-diagonal-product result in this section; it is the standard corollary
the lesson derives on screen — repeatedly expanding down the sparse first column
leaves only the diagonal entry times the (smaller) triangular minor, and the
recursion bottoms out at the diagonal product. This is exactly the sparse-column
strategy of Example 1.7 (p. 365, lines 406-436) applied to a triangular matrix.
Noted as a standard corollary, verified numerically below. **ok.**

## Problem s4 — first-row expansion of A = [[2,1,1],[1,2,1],[1,1,2]] (`given`, `step1`, `step3`, `answer`, check)

Our own matrix (numbers changed from Hefferon's Example 1.6 / Exercise 1.14).
Expanding along the top row with signs +,−,+ (Theorem 1.5, p. 365): the three
minors are det[[2,1],[1,2]] = 3, det[[1,1],[1,2]] = 1, det[[1,2],[1,1]] = −1, so
det A = 2(3) − 1(1) + 1(−1) = 6 − 1 − 1 = 4. The gate re-runs `check.expr`
`2*(2*2-1*1) - 1*(1*2-1*1) + 1*(1*1-2*1)`, declared `value: 4`, tol 1%.

```python
import numpy as np
A = np.array([[2,1,1],[1,2,1],[1,1,2]], float)
s4_expr = 2*(2*2-1*1) - 1*(1*2-1*1) + 1*(1*1-2*1)
print("cofactor expansion along row 1 =", s4_expr)
print("minors: det[[2,1],[1,2]]=", 2*2-1*1,
      " det[[1,1],[1,2]]=", 1*2-1*1,
      " det[[1,2],[1,1]]=", 1*1-2*1)
print("np.linalg.det(A) =", round(np.linalg.det(A), 12))
print("s4 check value   =", s4_expr)
```

output:
```
cofactor expansion along row 1 = 4
minors: det[[2,1],[1,2]]= 3  det[[1,1],[1,2]]= 1  det[[1,2],[1,1]]= -1
np.linalg.det(A) = 4.0
s4 check value   = 4
```

det A = 4, agreeing with numpy and with `check.expr` = 4 = `value`.
**Verdict: ok.**

## Problem s5 — triangular shortcut for B = [[3,2,1],[0,2,4],[0,0,5]] (`given2`, `step1b`, `step2b`, `answer2`, check)

Our own upper-triangular matrix (numbers changed). Expanding down the first
column (3,0,0), the two zero entries kill their terms, leaving det B = 3·det[[2,4],
[0,5]] = 3·10. That 2x2 is itself triangular (det = 2·5 = 10), so det B =
3×2×5 = 30 — the product of the diagonal (`step2b`, `answer2`). The gate re-runs
`check.expr` `3*2*5`, declared `value: 30`, tol 1%.

```python
import numpy as np
B = np.array([[3,2,1],[0,2,4],[0,0,5]], float)
s5_expr = 3*2*5
print("corner minor det[[2,4],[0,5]] =", 2*5-4*0)
print("diagonal product 3*2*5        =", s5_expr)
print("np.linalg.det(B) =", round(np.linalg.det(B), 12))
print("s5 check value   =", s5_expr)
```

output:
```
corner minor det[[2,4],[0,5]] = 10
diagonal product 3*2*5        = 30
np.linalg.det(B) = 30.0
s5 check value   = 30
```

det B = 30, agreeing with numpy and with `check.expr` = 30 = `value`.
**Verdict: ok.**

## Not from Hefferon (our own numbers)

Both worked problems use our own 3x3 matrices — s4: A = [[2,1,1],[1,2,1],[1,1,2]]
(symmetric, det 4 by first-row expansion); s5: B = [[3,2,1],[0,2,4],[0,0,5]]
(upper triangular, det 30 = diagonal product). These are not Hefferon's worked
examples (his §III examples use [[1,2,3],[4,5,6],[7,8,9]] with det 0 and the
sparse [[1,5,0],[2,1,3],[-1,0,...]] of Example 1.7). The Laplace expansion
theorem (Theorem 1.5, p. 365), the minor/cofactor definition and (−1)^{i+j} sign
(Definition 1.2, p. 364; Example 1.4, p. 364), expansion along any row or column
(Theorem 1.5 / Examples 1.6-1.7, p. 365), and the sparse-column strategy
(Example 1.7, p. 365) are all Hefferon's, applied to our numbers. The
triangular-determinant-equals-diagonal-product result is a standard corollary the
lesson derives from repeated sparse-column expansion (upper-triangular defined at
Exercise 1.26, p. 368).
